## 逐模块详细论证

### M1: 州级全民健康信息平台

| 评估维度 | 内容 |
|----------|------|
| **现状有什么** | 州卫健委"互联网+医疗健康"一期(约2022年)和二期(2025.12刚上线/273.5万)，但功能定位为"互联网+"便民服务，不具备全州数据汇聚、交换、EMPI、BI等核心平台能力。13县数据各自孤立。 |
| **缺什么** | 缺全州统一的：数据交换引擎(ESB+FHIR适配)、患者主索引(EMPI)、统一身份认证(SSO)、数据质控、综合管理BI、14项医共体监测指标自动采集 |
| **为什么必须建** | ①国卫办规划函〔2025〕63号明确要求5大领域36项功能；②13县各自招标正在形成新孤岛——茂县4900万/松潘663万/阿坝390万等均独立建设，若无州级平台统一汇聚，未来打通成本翻倍；③八统一中"信息统一"是其他七统的技术底座 |
| **改造还是新建** | 🆕**新建**。州卫健委现有系统定位不同，无法改造为全民健康信息平台 |
| **改造可行性** | 不适用——此为全州性空白 |
| **投入** | 州平台800万 + 13县平台1,950万 + 基础设施600万 = 3,350万 |
| **预期效果** | 13县数据全量汇聚、患者EMPI跨县识别、14项指标自动上报、检查检验结果全州互认 |
| **优先级** | **P0** — 没有这个，后面所有系统都是新的孤岛 |

| 政策依据 | 文号/文件 | 条款/内容 | 强度 |
|----------|----------|----------|:---:|
| 紧密型县域医共体信息化功能指引 | 国卫办规划函〔2025〕63号 | 第五方面"基层医疗卫生综合管理"，明确8项统一管理功能 | 🔴强制 |
| 四川省医共体建设实施方案 | 川卫发〔2024〕9号 | "八统一"之"信息统一"——建设全民健康信息平台 | 🔴强制 |
| 全国互联互通标准化成熟度测评 | 2020版 | 四级甲等要求统一平台+EMPI+ESB | 🔴强制 |
| 医共体监测指标体系(2024版) | 国卫办基层发〔2024〕22号 | 14项指标需自动采集，人工填报无法满足时效和准确性 | 🔴强制 |

| 行业案例参考 | 关键做法 | 可比性 |
|-------------|---------|:---:|
| 江苏东台 | "一云一网一平台"，23机构+328村卫生室全接入 | 平原模式→高原需加5G边缘 |
| 江西全省 | 省统建平台+2159卫生院+20769村卫生室作为节点 | 省级统筹→阿坝可州级仿效 |
