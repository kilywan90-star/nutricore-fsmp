方式A：nginx 本地代理（国内推荐）
在有公网IP的国内服务器上，nginx.conf 添加：
location /proxy/ { resolver 114.114.114.114; set $target $arg_url; proxy_pass $target; proxy_ssl_server_name on; proxy_read_timeout 120s; proxy_buffering off; add_header Access-Control-Allow-Origin *; }
重启 nginx 后，代理地址填：http://你的服务器IP/proxy/

方式B：Cloudflare Worker（海外）
workers.cloudflare.com → 创建 → 粘贴 → 部署
export default {async fetch(r){const u=new URL(r.url).searchParams.get('url');return new Response((await fetch(u)).body,{headers:{'Access-Control-Allow-Origin':'*'}});}}
部署后填入 https://xxx.workers.dev
