## 一、我们收集哪些信息

### 1.1 您主动提供的信息

| 信息类别 | 具体内容 | 用途说明 |
|---------|---------|---------|
| 账号信息 | 手机号码（哈希存储）、微信OpenID | 创建账号、登录认证、密码找回 |
| 健康评估信息 | 年龄、性别、身高、体重、腰围、家族病史、运动习惯、空腹血糖值 | 进行糖尿病风险评估 |
| 血糖记录 | 血糖测量值、测量类型（空腹/餐前/餐后/睡前/随机）、测量时间、备注 | 血糖趋势分析和预警 |
| 用药信息 | 药物名称、剂量、服用频率、服用时间 | 用药提醒和管理 |
| 化验单信息 | 化验单照片、化验指标结果 | AI解读化验报告 |
| 对话信息 | 与AI健康教练的对话内容 | 提供个性化健康指导 |

### 1.2 系统自动收集的信息

| 信息类别 | 具体内容 | 用途说明 |
|---------|---------|---------|
| 设备信息 | 操作系统类型、浏览器版本、设备型号 | 优化系统兼容性和显示效果 |
| 日志信息 | 访问时间、操作记录、IP地址 | 系统安全维护和故障排查 |
| 使用统计 | 功能使用频率、页面停留时间 | 改进系统功能和用户体验 |

### 1.3 我们不收集的信息

- **精确位置信息**：我们不会通过GPS获取您的精确位置
- **通讯录信息**：我们不会读取您设备的通讯录
- **生物识别信息**：我们不会采集指纹、面部特征等生物信息（化验单照片仅用于OCR文字识别，不用于身份识别）

## 二、我们如何使用信息

### 2.1 使用目的

| 使用场景 | 使用的信息 | 法律依据 |
|---------|-----------|---------|
| 提供糖尿病风险评估 | 年龄、BMI、腰围、家族史、运动习惯、空腹血糖 | 您的明确同意 + 医疗服务需要 |
| 血糖趋势分析与预警 | 血糖记录数据 | 您的明确同意 + 医疗服务需要 |
| AI化验单解读 | 化验单照片、化验指标 | 您的明确同意 + 医疗服务需要 |
| 用药提醒 | 用药计划信息 | 您的明确同意 + 医疗服务需要 |
| AI健康指导 | 健康评估数据、血糖数据、用药数据 | 您的明确同意 + 医疗服务需要 |
| 医生查看病情 | 经脱敏的临床数据 | 医疗服务需要 + 医生职责 |
| 系统优化与改进 | 使用统计数据（脱敏后） | 合法利益（改进服务质量） |
| 科研分析（需额外同意） | 脱敏后的聚合数据 | 您的单独明确同意 |

### 2.2 AI推理的数据处理方式

本系统使用大型语言模型（LLM）提供AI健康教练和报告解读服务。在将数据发送至AI服务之前，系统会执行以下安全处理：

1. **白名单过滤**：仅保留79个临床安全字段（如血糖值、HbA1c、用药记录等），所有可能识别个人身份的字段（姓名、手机号、身份证号、地址等）将被自动移除。
2. **脱敏标记**：过滤后的数据附带脱敏元数据，记录脱敏时间、移除字段列表和脱敏版本号。
3. **即时清除**：AI推理结果返回后，脱敏数据缓存将被即时清除。
4. **无持久化**：外部LLM服务商不会将本系统的请求数据用于模型训练。

### 2.3 我们不使用信息的方式

- 我们不会将您的健康数据用于自动决策（AI建议仅供医生参考，最终决策权在医生）。
- 我们不会将您的个人信息出售给任何第三方。
- 未经您的单独同意，我们不会将可识别身份的数据用于科研或商业用途。

## 三、信息存储与保护

### 3.1 存储位置

| 数据类别 | 存储位置 | 安全措施 |
|---------|---------|---------|
| 患者身份信息（L4） | 本院内网PostgreSQL数据库 | SHA-256哈希 + AES字段级加密 |
| 患者临床数据（L3） | 本院内网PostgreSQL数据库 | AES字段级加密 + RBAC访问控制 |
| 运营数据（L2） | 本院内网PostgreSQL数据库 | RBAC访问控制 |
| 备份数据 | 本地磁盘 + 可选S3/MinIO异地备份 | gzip压缩 + SHA-256校验 + 可选加密 |
| 日志数据 | 应用服务器本地文件 | 定期轮转，90天自动清理 |

### 3.2 安全保护措施

| 保护层面 | 具体措施 |
|---------|---------|
| **传输安全** | 全程TLS 1.3加密传输，防止数据在传输过程中被窃取或篡改 |
| **存储加密** | 敏感信息使用AES级加密存储（Fernet算法），不可逆身份信息使用SHA-256哈希 |
| **脱敏处理** | 姓名/手机号/身份证号在日志和展示层自动脱敏，仅显示掩码 |
| **访问控制** | 四级RBAC（管理员/科室主任/医生/患者）+ 科室数据隔离 + 患者授权检查 |
| **审计追踪** | 所有数据访问操作记录审计日志（操作人、时间、操作类型、资源ID） |
| **网络安全** | 防火墙 + WAF Web应用防火墙 + DDoS防护 + 内部网络隔离 |
| **定期备份** | 每日全量备份 + SHA-256完整性校验 + 异地容灾 |
| **漏洞管理** | 定期安全扫描 + 依赖漏洞自动检测 + 安全补丁及时更新 |

### 3.3 存储期限

| 数据类型 | 存储期限 | 超期处理 |
|---------|---------|---------|
| 临床诊疗数据 | 最低保存15年（依据电子病历管理规定） | 到期后评估是否继续保存 |
| 账号信息 | 账号存续期间 + 注销后90天 | 到期后安全删除或脱敏归档 |
| 系统日志 | 90天 | 自动清理 |
| 审计日志 | 180天 | 自动清理 |
| 备份文件 | 30天 | 自动过期删除 |

## 四、信息共享与对外提供

### 4.1 与医疗团队共享

您在系统中的临床数据（血糖记录、评估结果、化验报告、用药记录等）将共享给您的主治医生和科室主任，以便为您提供更好的诊疗服务。共享范围严格限制在医生执业所必需的范围内。

### 4.2 与第三方服务商共享

| 服务商类型 | 共享的数据 | 共享目的 | 安全保障 |
|-----------|----------|---------|---------|
| LLM服务商 | 脱敏后的临床指标（不含任何PHI） | AI健康教练和报告解读 | 数据已白名单过滤，合同约束禁止用于训练 |
| 云服务商 | 加密后的备份文件 | 异地容灾备份 | 加密传输+加密存储，服务商无法解密 |
| 短信服务商 | 通知内容和脱敏的联系方式 | 发送用药提醒 | 最小必要信息，用完即删 |

### 4.3 依法提供

在法律、法规要求或政府部门（如卫健委、网信办）的强制性要求下，我们可能会依法提供必要的个人信息。在提供前，我们会评估请求的合法性并最小化提供范围。

| 权利 | 说明 | 行使方式 |

| **更正权** | 发现信息不准确或不完整时，要求更正补充 | 通过账号设置页面修改，或联系医生修改临床数据 |

## 六、未成年人保护

本系统主要面向成年糖尿病患者。如果您是**未满14周岁的未成年人**，请勿自行使用本系统。

未满18周岁的用户使用本系统时，应由其监护人仔细阅读本隐私政策，并在监护人同意和指导下使用。监护人应妥善保护未成年人个人信息的安全。

如果我们发现未经监护人同意收集了未成年人的个人信息，我们将尽快删除相关数据。
