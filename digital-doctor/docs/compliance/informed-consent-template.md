## 一、系统简介

数字医生分身系统是{医院名称}内分泌科引入的一套AI辅助糖尿病管理平台。该系统整合了人工智能技术、中华医学会糖尿病学分会（CDS）临床指南和临床数据分析能力，旨在帮助您更好地管理血糖、提高治疗依从性。

系统包括以下功能模块：

| 功能模块 | 说明 |
|---------|------|
| 糖尿病风险评估 | 基于7项危险因素（年龄、BMI、腰围、家族史、运动习惯、空腹血糖、高血压）评估糖尿病风险 |
| AI化验单解读 | 拍照上传化验单，AI自动识别指标并提供解读，标注异常值与参考范围 |
| 血糖记录与趋势分析 | 记录日常血糖值，生成趋势图，计算目标范围内时间(TIR) |
| 用药提醒 | 设置用药计划，定时推送提醒，监测漏服情况 |
| AI健康教练 | 基于您的血糖数据和临床指南，提供个性化饮食、运动和生活方式建议 |
| 健康日报 | 每日推送健康提示和血糖管理知识 |

## 二、AI辅助诊疗说明

### 2.1 AI的工作原理

本系统的AI部分基于大型语言模型技术，通过分析您输入的健康数据（血糖值、用药情况、化验指标等），结合《中国2型糖尿病防治指南》等权威临床指南，生成个性化的建议和解读。

### 2.2 AI建议的局限性

**请您务必了解以下重要限制：**

1. **AI不是医生**：AI生成的建议完全基于您提供的数据和临床指南知识库，无法进行体格检查、无法了解您的完整病史、无法感知您的身体感受。
2. **建议仅供参考**：所有AI输出的内容（风险评估、化验解读、健康建议）仅供参考，不能作为诊断、治疗或用药调整的依据。
3. **最终决策权在医生**：任何诊断、用药方案调整、治疗方案变更必须由您的主治医生在面对面诊疗中做出。
4. **紧急情况不适用**：本系统不适用于医疗紧急情况。如出现以下症状，请**立即就医或拨打120**：

> 心慌、出冷汗、头晕、视力模糊、昏迷、晕倒、血糖仪无法测出、极高/极低血糖、发抖、面色苍白

### 2.3 我们如何保障AI安全性

- **数据脱敏**：所有发送给AI的数据均经过白名单过滤，移除姓名、手机号、身份证号等个人身份信息
- **紧急关键词检测**：当您输入的关键词包含上述紧急症状时，系统会优先提示就医而非AI回复
- **内容围栏**：AI输出受临床指南约束，不会给出超说明书用药、未经验证的偏方等不安全建议
- **医生复核**：所有AI建议在推送给您之前，支持医生复核和修改

## 五、风险告知

使用本系统可能存在以下风险，请您知晓：

| 风险类别 | 风险说明 | 严重程度 | 应对措施 |
|---------|---------|---------|---------|
| AI误判风险 | AI可能对复杂情况给出不够准确的建议 | 低（有医生复核） | AI建议需经医生确认，不可自行依此调整治疗 |
| 数据泄露风险 | 尽管有多层加密保护，任何信息系统都不能保证100%绝对安全 | 极低 | 加密+脱敏+审计+渗透测试 |
| 系统不可用风险 | 系统可能因维护、故障等原因暂时不可用 | 低 | 系统故障不影响线下诊疗，备有应急流程 |
| 过度依赖风险 | 患者可能过度依赖AI建议而忽视医生面诊 | 中 | 系统定期提示复诊，AI对话带就医提醒 |
| 隐私顾虑风险 | 部分用户可能对AI处理健康数据感到不适 | 个体差异 | 您有权随时停止使用AI功能或撤回同意 |

## 六、自愿参与与退出权利

### 6.1 自愿参与

使用本系统完全是自愿的。您是否参与不会影响您在{医院名称}的任何正常诊疗服务。如果您选择不参与，您将不会失去任何应有的医疗权益。

### 6.2 退出权利

您可以随时撤回同意，停止使用本系统。退出方式：

- 通过系统内"设置-隐私设置"撤回特定功能授权
- 通过"设置-账号注销"完全退出系统、删除全部数据
- 联系您的主治医生或{客服电话/邮箱}

退出后，我们将停止收集您的新数据，但已归档至电子病历的法律要求数据（如诊疗记录）将继续依法保存。

### 6.3 退出影响

退出系统后：
- 您将无法使用系统的AI功能
- 您的医生将无法通过系统查看您的远程数据
- 已产生的诊疗记录依法继续保存在电子病历中
- 您的正常门诊和住院诊疗不受任何影响
