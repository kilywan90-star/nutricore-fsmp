## 1. 研究背景与立题依据

### 1.1 临床背景

2型糖尿病(Type 2 Diabetes Mellitus, T2DM)是中国最主要的慢性病之一，成人患病率已达11.2%（Li Y, et al. BMJ 2020）。基层医疗机构承担了约60%以上的糖尿病日常管理任务，但面临内分泌专科医师严重不足、诊疗水平参差不齐、患者随访管理碎片化等突出问题（中华医学会糖尿病学分会, 2024）。

人工智能辅助诊疗系统在慢性病管理领域展现出显著潜力。近期系统综述（Huang Z, et al. Lancet Digital Health 2023;5(6):e370-e380）纳入42项研究，显示AI辅助糖尿病管理可使HbA1c平均下降0.49%（95% CI: 0.33%-0.65%），但仍缺乏在中国真实临床场景中的严格验证。

### 1.2 系统描述

数字医生分身（DDS-T2DM）是一套面向2型糖尿病全程管理的AI辅助诊疗系统，由以下核心模块构成：

| 模块 | 功能描述 | 技术特点 |
|------|----------|----------|
| 智能问诊分诊 | 个性化问卷生成 + 结构化病史摘要 | 规则引擎+LLM双阶段分析 |
| 鉴别诊断引擎 | 基于中国T2DM指南的分类推理 | 规则匹配置信度60% + LLM分析40% |
| 并发症风险评估 | DR/DN/DNeu/CVD四维风险分层 | China-PAR + KDIGO + Toronto标准 |
| 智能预警系统 | 血糖危急值/依从性/并发症筛查逾期 | 三级严重度分级(info/warning/critical) |
| 处方审核引擎 | 指南一致性+药物相互作用+禁忌证+过敏 | 10项安全维度综合审核 |
| 病历生成 | SOAP门诊病历+出院小结自动生成 | LLM驱动，含结构化回退 |
| 转诊协同 | 医联体内分级转诊+远程会诊辅助 | 临床摘要自动生成 |
| 基层支持 | 离线数据队列+村医辅助 | 适用于县域医疗场景 |
| 健康教练 | LLM驱动的患者生活方式指导 | 紧急症状自动识别 |

系统采用中国2型糖尿病防治指南(2024版)作为核心知识来源，药物数据库覆盖临床常用降糖药物，安全审核涵盖肾功能(eGFR分层)、肝功能、药物相互作用矩阵、过敏交叉反应、妊娠安全分级(FDA分类)及禁忌证多维检查。

### 1.3 立题依据与研究假设

**核心假设**: 在真实临床环境中，使用数字医生分身辅助诊疗系统的T2DM患者，其3个月HbA1c控制效果显著优于与同期历史对照组，且不增加不良事件发生率。

**次要假设**:
- H1: AI辅助可缩短医生诊前准备及病历书写时间≥30%
- H2: 系统预警对临床危急值的灵敏度≥95%，特异度≥85%
- H3: AI诊疗建议与独立内分泌科医师审查的指南一致性≥85%

### 1.4 参考先例研究

本研究设计参考以下已发表的临床验证研究：
- Avram R, et al. J Am Coll Cardiol 2023;82(17):1692-1702 — AI-ECG前瞻性验证(N=22,000)
- Wijnberge M, et al. JAMA 2020;323(11):1052-1060 — 术中低血压预警RCT
- Wallace BC, et al. JAMA Intern Med 2022;182(11):1198-1204 — 门诊AI辅助诊断

## 2. 研究设计

### 2.1 研究类型

前瞻性、多中心、观察性队列研究（单臂前后对照+历史对照）。

### 2.2 研究中心

| 编号 | 机构类型 | 科室 | 预期入组 | 角色 |
|------|----------|------|----------|------|
| Site-A | 三级甲等医院 | 内分泌科 | 100例 | 主中心 |
| Site-B | 县级医院(二级甲等) | 内分泌科/全科 | 100例 | 分中心 |

**中心选择依据**:
- Site-A: 代表三甲医院高复杂度患者群体(合并症多、用药方案复杂)，验证系统在专科场景的表现
- Site-B: 代表基层医疗机构(内分泌专科医师不足、患者教育资源有限)，验证系统在基层场景的赋能效果

### 2.3 样本量计算

**主要终点(HbA1c变化)样本量计算**:

基于文献报道(Ramirez M, et al. J Med Internet Res 2022;24(5):e35082)，AI辅助糖尿病管理的HbA1c降幅效应量Cohen's d = 0.35-0.50。取保守估计：

- 效应量 d = 0.35
- 显著性水平 α = 0.05 (双尾)
- 检验效能 1-β = 0.80
- 配对t检验

经G*Power 3.1计算，需67对完成随访的受试者。

考虑以下调整：
- 20%失访率: 67 / 0.80 = 84例
- 2个中心独立分析(最小各50例有效样本): 100例/中心
- 亚组分析需求(基线HbA1c、年龄分层): 需额外30%样本量

**最终确定样本量: N = 200例 (每中心100例)**

### 2.4 入排标准

**纳入标准**:
1. 年龄 ≥18岁且 ≤75岁
2. 符合中国2型糖尿病防治指南(2024版)诊断标准的确诊T2DM患者
3. 在入组前至少3个月在同一研究中心规律随访
4. 具备血糖自我监测条件(指尖血糖仪或CGM设备)
5. 患者本人或其法定代理人签署知情同意书

**排除标准**:
1. 1型糖尿病、妊娠期糖尿病或特殊类型糖尿病
2. 近3个月内有糖尿病酮症酸中毒(DKA)或高渗性高血糖状态(HHS)发作
3. 严重肝功能不全(Child-Pugh B/C级)
4. eGFR < 15 mL/min/1.73m²(慢性肾脏病5期)或正在接受透析治疗
5. 活动性恶性肿瘤(近6个月内接受过抗肿瘤治疗)
6. 预期寿命 < 6个月
7. 近3个月内参与其他干预性临床研究
8. 研究者判断存在影响依从性的严重精神疾病或认知障碍

### 2.5 患者分层

入组时按以下变量进行分层，确保各亚组样本均衡：

| 分层变量 | 水平1 | 水平2 | 水平3 |
|----------|-------|-------|-------|
| 治疗阶段 | 新诊断(确诊≤6个月) | 已治疗但控制不佳(HbA1c≥7.0%) | 良好控制(HbA1c<7.0%) |
| 基线HbA1c | <8.0% | ≥8.0% | — |
| 年龄 | <65岁 | ≥65岁 | — |

## 3. 评价指标

### 3.1 主要终点（Primary Endpoints）

| 编号 | 终点指标 | 定义与测量方法 | 统计假设 |
|------|----------|----------------|----------|
| P1 | HbA1c变化值 | ΔHbA1c = HbA1c(3个月) - HbA1c(基线)，高效液相色谱法(HPLC) | H0: Δ=0; H1: Δ<0 (下降) |
| P2 | 血糖目标范围时间(TIR)改善 | ΔTIR = TIR(3个月) - TIR(基线), 3.9-10.0 mmol/L, CGM≥14天数据 | 亚组分析(CGM使用者) |
| P3 | 患者依从率 | 依从率 = 实际血糖监测次数 / 应监测次数 × 100% + 药物持有率(MPR) ≥ 80% | 描述性+前后对比 |

**主要终点分析策略**: P1为确证性终点，P2-P3为探索性终点。多重性调整采用Holm-Bonferroni法。

### 3.2 次要终点（Secondary Endpoints）

| 编号 | 终点指标 | 定义与测量方法 | 分析策略 |
|------|----------|----------------|----------|
| S1 | 医生时间节省 | 诊前准备时间+病历生成时间 (分钟)，设对照组(传统工作流，同期不参与AI辅助的医生) | 独立样本t检验 |
| S2 | 患者满意度 - DTSQ | 糖尿病治疗满意度问卷(DTSQ)，入组时+研究结束时 | 配对t检验 |
| S3 | 预警灵敏度 | TP/(TP+FN) — 系统标记为危急值且被医生确认的比例 | 诊断性检验分析 |
| S4 | 预警特异度 | TN/(TN+FP) — 非危急情况未被系统误报的比例 | 诊断性检验分析 |
| S5 | AI建议指南一致性 | 2名独立内分泌科主治及以上医师盲法审查，判断AI建议是否符合指南，Cohen's kappa | Kappa≥0.80视为良好一致性 |
| S6 | 不良事件发生率 | 低血糖事件(血糖<3.9 mmol/L或需要他人帮助)、严重高血糖(>16.7 mmol/L需急诊) | Fisher精确检验 |

### 3.3 医生时间测量操作定义

**传统工作流(对照组)**:
1. 医生手动阅读患者历史病历(计时开始)
2. 记录关键信息于病历系统
3. 手写或电子录入病历(计时结束)
4. 总耗时 = 步骤1-3累计时间

**AI辅助工作流(干预组)**:
1. 医生查看AI生成的诊前问诊摘要 + 结构化病史(计时开始)
2. 确认/修改AI预填信息
3. 确认/编辑AI生成的SOAP病历(计时结束)
4. 总耗时 = 步骤1-3累计时间

每位医生至少记录10次就诊的时间消耗，取中位数。

### 4.3 系统日志自动采集

数字医生分身系统自动记录以下操作日志用于研究分析：
- 每次AI交互的请求时间戳与响应时间
- 规则引擎匹配结果与置信度
- LLM生成的诊断建议、处方审核结果、病历文本
- 预警触发时机、类型与医生确认/忽略状态

### 4.4 数据质量保证

1. **源数据核查(SDV)**: 每月由监督员对10%随机样本进行源数据比对
2. **缺失数据处理**: 缺失率>15%的变量在分析中标注并作敏感性分析(多重插补vs完全案例)
3. **异常值处理**: 超出±4 SD的连续变量值由临床专家复核，确认录入错误则修正，否则保留并标注
4. **HbA1c检测**: 两中心统一使用NGSP认证的HPLC方法，每月交叉质控

## 5. 统计分析计划 (Statistical Analysis Plan, SAP)

### 5.1 分析人群定义

| 人群 | 定义 | 用途 |
|------|------|------|
| ITT (意向治疗) | 所有签署知情同意并入组的患者 | 次要分析 |
| PP (符合方案) | 完成3个月随访且系统使用≥75%就诊次数的患者 | 主要分析 |
| Safety (安全性) | 所有至少使用过1次系统的入组患者 | 安全性分析 |

### 5.2 主要终点分析方法

**P1: HbA1c变化值**

主要分析：配对t检验，双侧α=0.05

```
H0: μ_ΔHbA1c = 0
H1: μ_ΔHbA1c ≠ 0

效应量: Cohen's d = |mean(ΔHbA1c)| / SD(ΔHbA1c)
95% CI: 基于t分布的自举法(Bootstrap, B=1000)
```

**历史对照比较**: 采集同一中心入组前6个月、相同入排标准的T2DM患者的常规诊疗HbA1c数据(N≥150)，以倾向性评分匹配(PSM)1:1匹配基线特征(年龄, 性别, 基线HbA1c, 病程, 治疗方案)，比较ΔHbA1c的组间差异（独立样本t检验或Wilcoxon秩和检验）。

**灵敏度分析**:
1. ANCOVA：以基线HbA1c为协变量
2. 缺失数据多重插补(MICE, m=20)
3. 排除基线HbA1c<6.5%的患者（已达标，天花板效应）

### 5.3 次要终点分析方法

| 终点 | 统计方法 | 效应量指标 |
|------|----------|------------|
| 医生时间节省 | 独立样本t检验(Mann-Whitney U备选) | Cohen's d |
| DTSQ满意度 | 配对t检验(基线vs 3月) | 均值差(95% CI) |
| 预警灵敏度 | Wilson法计算95% CI | ROC-AUC |
| 预警特异度 | Wilson法计算95% CI | ROC-AUC |
| 指南一致性 | Cohen's kappa + 百分比一致性 | Kappa (95% CI) |
| 不良事件 | Fisher精确检验 | 风险差(95% CI) |

### 5.4 亚组分析(预设)

| 亚组 | 分层变量 | 分析目的 | 交互检验 |
|------|----------|----------|----------|
| 基线HbA1c | <8.0% vs ≥8.0% | 验证系统对不同控制水平的效果 | 交互项P值 |
| 年龄 | <65岁 vs ≥65岁 | 验证老年患者的适用性 | 交互项P值 |
| 中心类型 | 三甲 vs 县级 | 验证不同层级医疗机构的效果差异 | 中心×处理的交互 |
| 糖尿病病程 | <5年 vs 5-10年 vs >10年 | 探索病程对AI辅助效果的影响 | 分组比较 |
| 并发症数量 | 0-1个 vs ≥2个 | 探索系统对复杂患者的适用性 | 分组比较 |

**亚组分析多重性**: 亚组分析结果标注为探索性分析，不作多重性调整，P值仅为描述性。

### 5.5 中期分析

不设中期分析。安全性数据由DSMB每2个月审查一次。

### 6.3 知情同意

- 研究目的与流程说明(通俗语言)

**医生知情同意书核心要素**:
- 工作流程数据采集说明(就诊时间记录)
- AI辅助的定位说明
- 保密义务

### 6.4 数据隐私与保护

| 措施 | 实现 |
|------|------|
| 患者身份脱敏 | SHA-256哈希(name_hash), 仅保留出生年份(birth_year) |
| PHI加密 | AES-256-GCM加密存储受保护健康信息 |
| 数据传输 | TLS 1.3加密传输 |
| 审计追踪 | 全操作审计日志(operation_audit)，记录每次数据访问 |
| 数据存储 | 研究数据库独立于临床数据库，位于医院内网服务器 |
| 访问控制 | RBAC三级权限(管理员/科室主任/医生)，科室级数据隔离 |
| LLM数据安全 | 发送至LLM前经sanitize_clinical_data()脱敏处理 |

### 6.5 数据共享声明

去标识化后的个体参与者数据(IPD)在研究发表后24个月内，可向通讯作者提出合理申请并签署数据使用协议后获取。研究方案和统计分析计划将在注册时同步公开。

## 7. 安全性监测

### 7.1 不良事件定义与报告

**严重不良事件(SAE)**:
- 死亡(全因)
- 危及生命的事件(DKA, HHS, 严重低血糖需他人协助)
- 需住院治疗或延长住院时间
- 导致显著或永久残疾

**AI相关不良事件(AI-AE)**:
- AI遗漏危急值导致临床延迟处理
- AI误报导致不必要的急诊就诊
- AI生成内容包含虚构信息(幻觉)导致临床误导

**报告时限**:
- SAE: 获知后24小时内报告主要研究者，7日内书面报告伦理委员会
- AI-AE: 获知后48小时内报告主要研究者

### 7.2 数据安全监察委员会(DSMB)

**组成**(5人，独立于研究团队):
- 内分泌科专家 2名(非参研中心)
- 生物统计学专家 1名
- 医学伦理学专家 1名
- AI/医学信息学专家 1名

**职责**:
- 每2个月审查安全性数据(不良事件发生率, 严重程度分布)
- 评估风险/获益比是否仍支持研究继续
- 审查并裁定AI相关不良事件的因果关系

### 7.3 暂停/终止规则

研究将在以下任一情况下暂停入组，由DSMB评估后决定是否恢复：

1. **安全性终止规则**:
   - SAE发生率在任一组超过15%
   - AI-AE导致临床伤害事件≥3例
   - 严重低血糖发生率较基线增加≥50%

2. **无效性终止规则**:
   - 中期分析(入组50%后DSMB审查)显示HbA1c变化的条件检验效能(Conditional Power) < 20%

3. **实施可行性终止规则**:
   - 入组速度低于计划50%持续≥2个月
   - 系统可用性(uptime) < 95%

### 附录C: DTSQ问卷(中文版)

Bradley C. Diabetes Treatment Satisfaction Questionnaire (DTSQ). 本研究使用DTSQs(状态版)和DTSQc(变化版)，共8题，6点Likert量表(0=非常不满意, 6=非常满意)。总分范围0-36分，分数越高表示治疗满意度越高。中文版经Cronbach's α=0.85验证(Liu Y, et al. 2016)。

### 附录D: 医生可用性调查问卷

自编结构化问卷，12题，5点Likert量表。维度包括：
- 系统易用性(3题)
- AI建议有用性(3题)
- 工作流程整合度(3题)
- 总体满意度(3题，含1题开放式反馈)

### 附录E: 样本量计算详细过程

```
G*Power 3.1.9.7
Test: Means - Difference between two dependent means (matched pairs)
Analysis: A priori - Compute required sample size
Input:
  Tail(s) = Two
  Effect size dz = 0.35
  α err prob = 0.05
  Power (1-β err prob) = 0.80

Output:
  Noncentrality parameter δ = 2.866
  Critical t = 1.997
  Df = 66
  Total sample size = 67

Adjustments:
  Attrition (20%): 67 / 0.8 = 84
  Two center minimum: 100/center to allow independent analysis
  Subgroup analysis buffer (30%): additional samples for stratification
  Final: 200 patients (100/center)
```
