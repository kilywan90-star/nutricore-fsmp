# 软件即医疗器械（SaMD）自我评估报告

**产品名称**: 数字医生分身 / Digital Doctor Clone  
**版本**: 1.0  
**评估日期**: 2026-05-30  
**评估依据**: NMPA《医疗器械分类目录》(2017版, 2022修订); NMPA《人工智能医疗器械注册审查指导原则》(2022); IMDRF/SaMD WG/N12 Framework  

---

## 1. 产品描述

数字医生分身是一个面向2型糖尿病管理的临床决策支持系统（CDSS）。系统集成规则引擎与大语言模型（LLM），为医生提供辅助决策建议、处方合理性提醒和并发症风险评估。系统包含医生端（Web）、患者端（Web）和基层端（Web）三个前端。

**关键技术特征**:
- 规则引擎驱动的指南符合性检查（中国2型糖尿病防治指南2024版）
- LLM辅助的鉴别诊断分析（非独立诊断）
- 处方安全审查（药物相互作用、禁忌症、肾肝功能剂量调整、过敏交叉参考、妊娠安全性）
- 基层筛查和随访管理
- 全链路PHI去标识化和加密

---

## 2. 预期用途

**预期用途声明**: 数字医生分身是一款临床决策支持软件，旨在：

1. 基于2型糖尿病防治指南，为医生提供**辅助决策建议**（非独立诊断）
2. 对已开具处方进行**合理性提醒**（药物相互作用、禁忌症、剂量调整）
3. 评估2型糖尿病患者**并发症风险**并提供**筛查建议**
4. 生成预问诊摘要和患者管理辅助信息

**预期使用场景**: 门诊诊室、住院病房、基层卫生机构  
**预期用户**: 内分泌科医生、基层全科医生、科室主任  
**禁忌使用**: 本软件不得用于直接诊断疾病、独立开具处方或替代医生的临床判断

---

## 3. 功能分析（非医疗器械判定依据）

### 3.1 非独立诊断

**设计约束**: 所有AI辅助分析输出均附带强制性免责声明和指南引用。

**输出格式规范**:
- AI输出始终包含短语: "基于指南§X.X，建议临床医生考虑..."（非 "诊断为..."）
- AI输出不会生成确定性诊断结论
- 每个输出卡片均显示: "* 本内容由AI生成，仅供临床参考，最终决策权归医生所有"

**证据截图（描述）**:
- 鉴别诊断面板: 显示"鉴别诊断"表格（概率、支持证据、需排除），无"最终诊断"字样
- 处方审核面板: 显示"合理性提醒"分级（安全/需注意/不安全），无"处方更改"强执行

### 3.2 强制性人机交互

**设计约束**: 每条AI建议必须经医生确认方可采纳。

**确认机制**:
- 每次鉴别诊断/处方建议生成后，需医生点击复选框确认（数字审计轨迹）
- 确认操作不可跳过，不可预填充
- 系统不自动执行任何临床操作（不开具处方、不安排检查、不调整剂量）

**证据截图（描述）**:
- 鉴别诊断面板底部: "发送至病历"按钮（非"执行诊断"）

### 3.3 非闭环控制

**设计约束**: 系统不直接控制任何临床决策或治疗过程。

**禁止的操作**:
- 系统不开具处方（药物剂量仅为参考建议）
- 系统不直接下单检验检查
- 系统不更改患者的治疗计划
- 处方权、诊断权完全掌握在医生手中

### 3.4 功能分类映射

| 系统功能 | 是否医疗器械 | NMPA规则依据 |
|---------|------------|------------|
| 鉴别诊断分析 | 否 — CDSS辅助决策 | 目录21-04-01 注: 非独立诊断的CDSS不属于医疗器械 |
| 处方安全审查（相互作用、禁忌症） | 否 — 药物信息参考 | 提供已知药物相互作用信息，不涉及独立判断 |
| 肾功能剂量调整建议 | 否 — 剂量参考 | 基于已公开药品说明书，非独立决策 |
| 并发症风险评估 | 否 — 风险筛查辅助 | 筛查工具，结果需医生确认 |
| 基层随访提醒 | 否 — 管理辅助 | 非诊断/治疗功能 |
| HOMA-IR/HOMA-β计算 | 否 — 公式计算工具 | 标准数学公式，非AI独立决策 |

## 4. 分类合理性论证

### 4.1 NMPA分类规则适用性分析

**参照**: NMPA《医疗器械分类目录》子目录21-04 "医用软件"

| 规则编号 | 规则内容 | 产品符合性 | 论证 |
|---------|---------|----------|------|
| 21-04-01 | 用于诊断的软件，若其输出结果不依赖操作者进一步判断即为诊断结论，则属于医疗器械 | **不符合** | 系统输出为"建议"和"提醒"，附带强制性人机交互确认机制，不输出确定性诊断结论 |
| 21-04-02 | 用于治疗规划/药物计算的软件 | **不符合** | 系统不直接开具处方或控制给药设备 |
| 21-03-01 | 具有辅助诊断功能的独立软件 | **需关注** | 属于CDSS范畴。根据NMPA《人工智能医疗器械注册审查指导原则》第4.2节，不独立给出诊断结论的CDSS可不属于医疗器械管理 |

### 4.2 国际对标

| 监管机构 | 分类 | 依据 |
|---------|------|------|
| 美国FDA | 非器械（CDS豁免） | 21st Century Cures Act §3060(a), CDS豁免条件：(1)不独立分析医学图像/信号；(2)显示引用来源和依据；(3)不为特定患者提供唯一的输出 |
| 欧盟MDR | 非医疗器械（Rule 11豁免） | MDR Annex VIII Rule 11(a): 仅提供参考信息而不直接用于诊断或治疗决策的软件 |
| IMDRF/SaMD | 类别I（低风险） | 仅提供信息以支持临床决策，不直接驱动治疗 |

### 4.3 产品满足CDS豁免四要素

根据FDA CDS Guidance (2022):

1. **不分析医学图像/信号** ✓ — 本系统基于结构化临床数据（化验值、药品名称、病史），不处理影像或生理信号
2. **显示证据和引用** ✓ — 所有输出包含指南引用（如"中国2型糖尿病防治指南(2024版) §6.3"）
3. **不具备锁定输出** ✓ — 医生可以任何时候忽略或覆盖AI建议
4. **不旨在替代医生判断** ✓ — 系统角色定位为"辅助参考"，所有输出经医生确认方转化为临床行动

## 5. 风险分析

| 风险项 | 严重程度 | 发生概率 | 风险等级 | 控制措施 |
|--------|---------|---------|---------|---------|
| AI误诊导致错误治疗 | 严重 | 低 | 中 | (1)非确定性输出 (2)强制性人机交互确认 (3)指南引用可追溯 |
| 药物相互作用漏检 | 中等 | 低 | 低 | (1)规则引擎+LLM双重验证 (2)药物数据库定期更新 (3)过敏交叉参考 |
| 患者误用AI输出 | 中等 | 极低 | 低 | (1)患者端仅展示健康管理信息 (2)不下发诊断/处方给患者端 |
| 数据泄露 | 严重 | 极低 | 低 | (1)全链路PHI去标识化 (2)AES-256传输加密 (3)审计日志 |
| 基层误用系统替代医生 | 中等 | 低 | 中 | (1)基层端设计为"筛查+随访" (2)不下发AI诊断到基层端 |

**综合风险评估**: **低风险**。产品设计已充分考虑安全边界，且不独立驱动临床决策。

---

## 6. 结论

基于以上分析，**数字医生分身不符合NMPA医疗器械定义，属于非医疗器械CDSS产品**。具体依据：

1. **非独立诊断**: 所有AI输出为"建议"/"提醒"格式，不产生确定性诊断结论
2. **强制性人机交互**: 每条AI建议需医生手动确认方可采纳，形成数字审计轨迹
3. **非闭环控制**: 系统不直接开具处方、安排检查或调整治疗
4. **功能定位**: 产品本质为参考信息提供工具（CDSS），非医疗器械
