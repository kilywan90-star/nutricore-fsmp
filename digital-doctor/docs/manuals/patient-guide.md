### 方式一：微信小程序登录（推荐）

**步骤1：扫码进入小程序**

使用微信扫描医院提供的二维码，进入"数字医生分身"小程序。

**步骤2：授权登录**

[图片：微信授权页面截图]

[图片：个人信息完善页面截图]

3. 输入短信验证码，设置密码（8位以上，含数字和字母）
4. 点击"注册并登录"

[图片：手机号注册页面截图]

## 二、糖尿病风险评估怎么填

糖尿病风险评估基于《中国2型糖尿病防治指南》，通过7项危险因素综合计算您的糖尿病风险等级。

### 评估步骤

**步骤1：进入评估页面**

在首页点击"糖尿病风险评估"卡片。

[图片：首页风险评估入口截图]

**步骤2：填写评估信息**

按提示逐项填写以下信息：

| 评估项目 | 填写说明 | 示例 |
|---------|---------|------|
| 年龄 | 填写当前周岁年龄（18-120岁） | `45` |
| BMI（体质指数） | BMI = 体重(kg) / 身高(m)²，例如体重70kg、身高1.7m，BMI = 70/2.89 ≈ 24.2 | `24.2` |
| 腰围 | 用软尺测量肚脐水平位置的腰围（厘米），范围50-200cm | `88` |
| 家族糖尿病史 | 父母、兄弟姐妹、子女中是否有人确诊糖尿病 | 选"是"或"否" |
| 运动习惯 | 每周是否进行至少150分钟中等强度运动 | 选"高/中/低" |
| 空腹血糖 | 最近一次空腹血糖检测值（mmol/L），范围2.0-30.0 | `6.5` |
| 高血压 | 是否已被医生诊断为高血压 | 选"是"或"否" |

[图片：风险评估填写页面截图]

**步骤3：查看评估结果**

提交后，系统会显示：

- **风险等级**：低风险 / 中风险 / 高风险
- **总评分**及最高分对照
- **各因素得分明细**：直观看出哪个因素贡献最大
- **个性化建议**：根据您的高风险因素给出针对性建议，例如：
  - 空腹血糖偏高 → 建议尽快就医检查
  - 运动不足 → 建议每周至少150分钟中等强度运动
  - BMI偏高 → 建议控制饮食，减轻体重

[图片：评估结果页面截图]

### 注意事项

- 评估结果仅供参考，不能替代专业医学诊断
- 如果评估结果显示高风险，请尽快携带评估结果就医
- 可以随时重新评估，系统会记录历史评估结果

## 三、AI化验单解读怎么用

### 操作步骤

**步骤1：进入报告解读页面**

在首页点击"AI报告解读"卡片。

[图片：AI报告解读入口截图]

**步骤2：上传化验单照片**

点击"拍照/上传化验单"按钮，选择以下方式之一：
- **拍照**：用手机摄像头拍摄化验单
- **相册选择**：从手机相册中选择已拍好的化验单照片

拍摄建议：
- 确保光线充足，化验单平放无褶皱
- 将完整化验单放入取景框内
- 避免手指遮挡文字

[图片：拍照上传界面截图]

**步骤3：等待识别与解读**

系统将自动进行OCR（光学字符识别）提取化验指标，然后由AI进行解读。通常5-15秒即可完成。

[图片：识别进度截图]

**步骤4：查看解读结果**

解读结果包含：

- **识别指标列表**：系统提取的各项化验指标及其数值
- **参考范围对照**：正常值范围，超标的指标用红色标注
- **AI解读说明**：用通俗易懂的语言解释各项指标的含义
- **建议行动**：如指标异常，给出就医建议

[图片：解读结果页面截图]

### 支持的化验单类型

| 类型 | 支持项目举例 |
|------|------------|
| 血糖相关 | 空腹血糖、餐后2小时血糖、HbA1c（糖化血红蛋白） |
| 血脂 | 总胆固醇(TC)、LDL、HDL、甘油三酯(TG) |
| 肾功能 | 肌酐、尿素氮、尿微量白蛋白 |
| 肝功能 | ALT、AST |

## 四、如何记录血糖

### 操作步骤

**步骤1：进入血糖记录页面**

在首页点击"血糖记录"卡片。

[图片：血糖记录入口截图]

**步骤2：添加血糖记录**

点击右下角的"+"按钮，填写：

| 字段 | 说明 |
|------|------|
| 血糖值 | 输入血糖仪显示的数值（mmol/L），范围1.0-40.0 |
| 测量类型 | 选择：空腹 / 餐前 / 餐后2小时 / 睡前 / 随机 |
| 测量时间 | 默认当前时间，可手动调整（用于补录历史记录） |
| 备注 | 可填写特殊情况，如"今天吃了甜食"、"运动后测量" |

填写完成后点击"保存"。

[图片：添加血糖记录页面截图]

**步骤3：查看血糖趋势**

血糖记录列表按时间倒序展示，顶部显示统计卡片：

| 统计指标 | 说明 |
|---------|------|
| 记录次数 | 总计记录的血糖次数 |
| 平均血糖 | 所有记录的平均值 |
| 最高/最低 | 记录期间的最高值和最低值 |
| 目标范围内时间(TIR) | 血糖在3.9-10.0 mmol/L范围内的时间占比 |

[图片：血糖趋势统计截图]

系统会生成血糖趋势图，直观展示您的血糖波动情况。

[图片：血糖趋势图表截图]

### 血糖监测建议

| 监测频率 | 适用人群 |
|---------|---------|
| 每天4-7次 | 血糖波动大、调整用药期间 |
| 每天1-2次 | 血糖控制稳定 |
| 每周2-4次 | 仅口服药、血糖控制良好 |
| 每3个月 | HbA1c（需医院抽血检查） |

### 血糖目标参考（个性化）

| 指标 | 一般目标 | 严格目标 |
|------|---------|---------|
| 空腹血糖 | 4.4-7.0 mmol/L | 4.4-6.1 mmol/L |
| 餐后2小时血糖 | < 10.0 mmol/L | < 7.8 mmol/L |
| HbA1c | < 7.0% | < 6.5% |

**注意**：具体目标请咨询您的主治医生，医生会根据您的情况设定个性化目标。

## 五、用药提醒怎么设置

### 操作步骤

**步骤1：进入用药提醒页面**

在首页点击"用药提醒"卡片。

[图片：用药提醒入口截图]

**步骤2：添加用药计划**

点击"添加药物"按钮，填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 药物名称 | 输入药品通用名或商品名 | `二甲双胍` |
| 剂量 | 每次服用的剂量 | `500mg` |
| 用药频率 | 选择"每天"或"每周指定日" | `每天` |
| 用药时间 | 选择具体的服药时间（可多选） | `08:00、20:00` |
| 起始日期 | 开始服药的日期 | `2026-01-15` |
| 结束日期 | 停药日期（选填） | 不填表示长期服用 |

[图片：添加用药提醒页面截图]

**步骤3：管理用药计划**

已添加的用药计划会以列表形式展示。每项显示：
- 药物名称和剂量
- 下次服药时间
- 漏服标记（如果错过服药时间会红色高亮）

可以对已有计划进行：
- **编辑**：修改剂量、时间等
- **暂停**：临时停用但不删除
- **删除**：永久删除该用药计划

[图片：用药计划列表截图]

### 用药提醒通知

到了设定的服药时间，系统会通过以下方式提醒：

1. **微信服务通知**（需在微信中开启）
2. **APP内通知**（页面顶部横幅提醒）
3. **短信通知**（可选，需在设置中开启）

通知内容包括：药物名称、剂量、服药时间。

[图片：用药提醒推送通知截图]

### 注意事项

- 请确保药物名称和剂量与医生处方一致
- 用药提醒仅为辅助工具，不能替代遵医嘱服药
- 如需调整用药方案，请务必先咨询医生

## 六、AI健康教练怎么用

### 功能介绍

AI健康教练是您的私人糖尿病管理助手，它结合了《中国2型糖尿病防治指南》知识和您的个人健康数据，为您提供：

- 饮食指导：根据您的血糖情况推荐合适的食物选择
- 运动建议：个性化的运动类型和强度建议
- 用药提醒解读：帮助您理解药物作用和注意事项
- 血糖分析：帮助您理解血糖波动的原因

### 操作步骤

**步骤1：进入AI健康教练页面**

在首页点击"AI健康教练"卡片。

[图片：AI健康教练入口截图]

**步骤2：开始对话**

页面底部有一个输入框，您可以像聊天一样向AI健康教练提问。例如：

| 您可以这样问 | 示例回答 |
|------------|---------|
| "我今天空腹血糖8.5，比昨天高了，怎么回事？" | AI会结合您的近期血糖数据，分析可能的原因（饮食、运动、用药等） |
| "糖尿病患者早餐吃什么好？" | AI会推荐低GI食物和搭配方案 |
| "饭后多久运动比较好？" | AI会根据指南建议饭后30-60分钟开始运动 |
| "忘记吃药了怎么办？" | AI会根据药物类型给出处理建议 |

[图片：AI健康教练对话界面截图]

**步骤3：查看历史对话**

页面显示您的历史对话记录，可以随时回顾之前的建议。

### 紧急情况自动检测

**重要**：当您在对话中提到以下症状时，系统会自动识别为紧急情况，优先提示就医而非AI回复：

> 心慌、出冷汗、头晕、视力模糊、昏迷、晕倒、血糖仪测不出、极高血糖(>30)、发抖、面色苍白

紧急回复示例：

> "您的症状需要立即引起重视。请立即测量血糖，如血糖<3.9mmol/L请立即补充15g速效碳水（如半杯果汁/3块方糖）；如症状持续不缓解，请立即拨打120或前往急诊。"

### 注意事项

- AI健康教练的建议仅供参考，不能替代医生诊断
- 紧急情况请直接就医或拨打120
- 系统不会将您的个人信息（姓名、手机号等）发送给AI
- 所有对话内容会对您的主治医生可见，帮助医生更好地了解您的关切

## 七、常见问题FAQ

### Q1: 系统的评估结果准吗？我的风险等级很高，是不是一定有糖尿病？

系统的风险评估基于《中国2型糖尿病防治指南》推荐的芬兰糖尿病风险评分（FINDRISC）改良模型，具有科学依据。但风险评估只是筛查工具，不能替代医学诊断。如果风险评估显示高风险，建议尽快到医院做口服葡萄糖耐量试验（OGTT）确诊。

### Q2: 我的血糖数据会被别人看到吗？

您的血糖数据仅供您和您的主治医生（以及科室主任）查看。所有数据都经过加密存储和传输。系统操作审计日志会记录每一次数据访问，确保不会发生越权查看。

### Q3: AI解读化验单的结果可靠吗？

AI解读基于光学字符识别(OCR)和大型语言模型技术。OCR识别准确率通常在95%以上，但对于手写化验单或模糊照片可能识别不准确。AI的解读仅供您快速了解化验结果，最终解读应由您的主治医生确认。

### Q4: 忘记记录血糖了，可以补录吗？

可以。在添加血糖记录时，点击"测量时间"字段即可选择之前的日期和时间进行补录。系统会按实际测量时间排列和统计。

### Q5: 用药提醒没有收到通知怎么办？

请检查：
1. 手机通知权限是否已开启
2. 微信服务通知是否已订阅
3. 用药计划是否仍处于"启用"状态（未被暂停）

如果以上都正确，请联系客服检查。

### Q6: 能否更换绑定的手机号？

如需更换绑定手机号，请联系医院客服或您的主治医生。出于安全考虑，患者不可自行修改关键身份信息。

### Q7: 不想用了，如何退出？我的数据能被删除吗？

您可以随时停止使用。如需删除所有个人数据：
1. 进入"我 - 设置 - 账号注销"
2. 阅读注销说明并确认
3. 提交注销申请

注销后，您的个人数据将被永久删除。但请注意，已纳入电子病历的诊疗数据依法需要继续保存。

### Q8: 系统支持哪些检查项目的化验单解读？

目前主要支持糖尿病管理常用指标：血糖（空腹/餐后）、HbA1c、血脂四项（TC/LDL/HDL/TG）、肾功能（肌酐/尿素氮）、肝功能（ALT/AST）等。如果化验单中包含了系统暂不支持的指标，该指标将被标记为"暂不支持"。

### Q9: 我可以让家人帮我看血糖数据吗？

目前系统不支持多账号关联。但我们建议您将血糖数据定期告知家人，或在复诊时请医生帮助导出数据。

### Q10: 系统要收费吗？

数字医生分身系统作为{医院名称}的院内医疗服务延伸，目前对在本院就诊的患者免费提供。具体费用政策如有变更，医院会提前通知。
