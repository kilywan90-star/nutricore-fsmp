## 一、登录与账号设置

### 1.1 首次登录

**步骤1：获取账号**

系统管理员会为您创建医生账号。账号信息（手机号和初始密码）会通过医院内部渠道发送给您。

**步骤2：登录系统**

在浏览器访问系统地址 `https://{医院域名}`，输入手机号和密码登录。

[图片：医生登录页面截图]

**步骤3：修改初始密码**

首次登录后，系统会提示您修改密码。请设置一个强度足够的密码（8位以上，含数字和字母）。

### 1.2 完善医生档案

登录后，点击右上角头像 -> "账号设置"，检查并完善以下信息：

| 字段 | 说明 |
|------|------|
| 职称 | 如"主任医师"、"主治医师"、"住院医师" |
| 执业证号 | 您的医师执业证书编号 |
| 所属科室 | 由管理员分配，不可自行修改 |
| 是否科室主任 | 由管理员设定，不可自行修改 |

[图片：医生档案设置页面截图]

### 1.3 账号安全

- 请勿将账号密码告知他人
- 每次离开工位建议锁定屏幕或退出登录
- 系统会在30分钟无操作后自动登出（JWT令牌过期）

## 二、患者列表与筛选

### 2.1 查看患者列表

登录后，点击左侧导航栏"患者管理"进入患者列表页面。页面顶部显示三个统计卡片：

| 统计指标 | 说明 |
|---------|------|
| 管理患者总数 | 您名下的有效患者数量（primary + consulting分配） |
| 未读预警 | 尚未确认的预警数量（红色表示有未处理预警） |
| 血糖控制不佳 | 最近血糖>10.0 mmol/L的患者数量（黄色警告） |

[图片：患者列表概览统计卡片截图]

### 2.2 患者列表字段说明

列表每行显示一个患者的基本信息：

| 字段 | 说明 |
|------|------|
| 患者摘要 | 显示脱敏标识（如 UUID前8位），不显示真实姓名 |
| 糖尿病类型 | 1型 / 2型 / 其他 |
| 风险等级 | 最近一次评估的风险等级 |
| 最近血糖 | 最近一次记录的血糖值及时间 |
| HbA1c | 最近一次糖化血红蛋白值 |
| 预警指示 | 如有未处理预警，显示红色标记 |
| 分配类型 | 您与该患者的关系：主要责任/会诊 |

[图片：患者列表页面截图]

### 2.3 筛选功能

使用页面顶部的筛选栏快速定位目标患者：

| 筛选方式 | 操作 |
|---------|------|
| 关键词搜索 | 输入患者UUID或相关关键词，支持模糊匹配 |
| 风险等级筛选 | 下拉选择：全部 / 低风险 / 中风险 / 高风险 |
| 分页浏览 | 底部翻页控件，每页显示20条，最多100条 |

### 2.4 我的患者 vs 科室患者

- **"我的患者"**：直接分配给您的患者（primary + consulting）
- **"科室患者"**（科室主任专属）：本科室所有医生的患者

点击左侧导航切换视图。

## 三、患者详情页解读

在患者列表中点击任意患者，进入患者详情页。该页面整合了该患者的全部健康数据。

### 3.1 页面布局

患者详情页分为以下区域：

[图片：患者详情页全貌截图]

### 3.2 基本信息区

| 信息项 | 展示方式 | 说明 |
|-------|---------|------|
| 患者标识 | UUID脱敏显示 | 性别、出生年份、糖尿病类型 |
| 诊断日期 | 日期 | 首次确诊日期 |
| HbA1c目标 | 数值 | 个性化控制目标（默认7.0%） |

### 3.3 指标趋势图怎么看

**血糖趋势图**

折线图展示患者近期的血糖变化，X轴为时间，Y轴为血糖值(mmol/L)。

图表包含多条颜色区带：

| 颜色 | 范围 | 含义 |
|------|------|------|
| 绿色区域 | 3.9-7.8 mmol/L | 目标范围内（良好控制） |
| 黄色区域 | 7.8-10.0 mmol/L | 偏高（需关注） |
| 红色区域 | >10.0 或 <3.9 mmol/L | 异常偏高/偏低（需干预） |

每个数据点圆点颜色对应当时的血糖状态。

[图片：血糖趋势图截图]

**目标范围内时间（TIR）**

饼图展示血糖在目标范围（3.9-10.0 mmol/L）内的时间占比：

- **绿色**：在范围内（目标>70%）
- **橙色**：高于范围
- **红色**：低于范围

[图片：TIR饼图截图]

### 3.4 血糖记录列表

按时间倒序展示患者的详细血糖记录：

| 列 | 说明 |
|----|------|
| 日期时间 | 测量时间 |
| 血糖值 | mmol/L |
| 测量类型 | 空腹/餐前/餐后/睡前/随机 |
| 备注 | 患者填写的备注信息 |

### 3.5 用药记录

显示患者当前启用的用药计划：

- 药物名称、剂量、用药频率
- 每日用药时间
- 计划起止日期

### 3.6 化验报告

展示患者上传并经过AI解读的化验单报告，包括识别指标和AI解读内容。

### 3.7 AI健康教练对话历史

显示患者与AI健康教练的对话记录，帮助了解患者近期的自我管理关切和疑问。

## 四、如何处理预警

### 4.1 预警颜色含义

系统根据预警严重程度使用三种颜色标记：

| 颜色 | 级别 | 触发条件（示例） | 建议响应时间 |
|------|------|----------------|------------|
| 🔴 红色 | 危急 (Critical) | 血糖<2.8 或 >25.0 mmol/L | 立即处理 |
| 🟡 黄色 | 警告 (Warning) | 血糖3.0-3.8 或 16.7-25.0 mmol/L | 2小时内 |
| 🔵 蓝色 | 信息 (Info) | 血糖3.9-4.3 或 10.0-13.9 mmol/L | 24小时内 |

### 4.2 预警来源

系统会自动从以下数据生成预警：

| 预警类型 | 触发条件 |
|---------|---------|
| 低血糖预警 | 血糖值 < 3.9 mmol/L |
| 高血糖预警 | 空腹血糖 > 7.0 或 餐后血糖 > 10.0 |
| 血糖波动预警 | 连续3次血糖波动幅度超过正常范围 |
| 漏服预警 | 超过规定服药时间2小时未记录打卡 |
| AI对话紧急预警 | AI健康教练对话中检测到紧急关键词 |

### 4.3 处理预警的步骤

**步骤1：查看预警列表**

在左侧导航栏点击"预警中心"，或在工作台首页查看"最近预警"列表。

[图片：预警中心页面截图]

**步骤2：查看预警详情**

点击单条预警，查看：
- 预警触发时间
- 关联的血糖值/事件
- 预警严重级别
- 参考的临床指南条目

**步骤3：处理预警**

根据预警类型采取相应措施：

| 预警场景 | 建议处理方式 |
|---------|------------|
| 严重低血糖(<3.0) | 立即电话联系患者，指导补充碳水，必要时安排急诊 |
| 中度低血糖(3.0-3.8) | 通过系统发送消息或电话提醒，指导调整饮食/用药 |
| 持续高血糖(>16.7) | 查看近期趋势，联系患者了解原因，必要时安排复诊 |
| 漏服提醒 | 发送提醒消息，下次复诊时评估依从性 |

**步骤4：确认预警**

处理完毕后，在预警详情页点击"确认"按钮。确认后的预警变为"已处理"状态，不再计入未读预警计数。

**步骤5：添加处理备注（可选）**

可在确认时添加处理描述，例如"已电话联系患者，血糖已恢复至5.2"。

### 4.4 批量操作

在预警列表页面，可以勾选多条预警后批量确认。

## 五、如何分配患者

### 5.1 患者分配类型

系统支持两种分配关系：

| 分配类型 | 说明 | 使用场景 |
|---------|------|---------|
| **主要责任（Primary）** | 该医生是患者的主治医生 | 患者挂该医生的门诊号，长期管理 |
| **会诊（Consulting）** | 该医生参与患者会诊 | 跨科室会诊、多学科协作诊疗(MDT) |

### 5.2 分配患者操作

**步骤1：进入患者详情页**

在患者列表中点击目标患者。

**步骤2：点击"分配"按钮**

在患者详情页顶部操作栏，点击"分配给我"按钮。

[图片：患者分配操作截图]

**步骤3：选择分配类型**

在弹出的对话框中，选择：
- "主要责任"：如果您是主治医生
- "会诊"：如果您参与会诊

点击"确认"完成分配。

### 5.3 更改责任医生

如果您需要将患者转给其他医生（如转科、医生轮换），请联系科室主任或管理员处理。医生不能直接将自己的患者转给其他医生。

### 5.4 科室主任的额外权限

科室主任可以：
- 查看本科室内所有医生的患者
- 将患者分配给本科室的任意医生
- 修改分配类型或解除分配

操作路径：患者详情页 -> "管理分配"（仅科室主任和管理员可见）

## 六、审计日志查看

### 6.1 审计日志说明

系统会记录所有与临床数据相关的操作，形成不可篡改的审计日志。日志包含：

| 字段 | 说明 |
|------|------|
| 操作时间 | 精确到秒的操作时间戳 |
| 操作人 | 执行操作的医生ID |
| 操作类型 | VIEW（查看）/ ASSIGN（分配）/ CREATE（创建）/ UPDATE（更新） |
| 资源类型 | patient / alert / report / medication |
| 资源ID | 被操作的具体资源标识 |
| 操作详情 | 额外的上下文信息 |

### 6.2 查看审计日志

拥有管理员权限的用户可以查看审计日志：

"系统管理" -> "审计日志"

支持按以下条件筛选：
- 操作人
- 操作类型
- 资源类型
- 时间范围

[图片：审计日志页面截图]

### 6.3 审计日志的作用

- **合规要求**：满足等保三级和医疗信息安全的审计要求
- **安全追溯**：发生安全事件时追溯操作链
- **质量评估**：分析医生的患者管理行为模式

## 七、临床场景示例

### 场景一：门诊场景使用流程

**背景**：患者张先生，45岁，2型糖尿病，今日门诊复诊。

**操作流程**：

| 步骤 | 操作 | 耗时 |
|------|------|------|
| 1 | 登录系统，在"我的患者"中搜索患者UUID | ~10秒 |
| 2 | 进入患者详情页，查看血糖趋势图（本次就诊间隔期的血糖控制情况） | ~30秒 |
| 3 | 查看TIR饼图，评估血糖整体达标情况 | ~10秒 |
| 4 | 查看用药计划和漏服记录，评估依从性 | ~20秒 |
| 5 | 查看AI健康教练对话历史，了解患者近期自述问题 | ~30秒 |
| 6 | 查看化验单AI解读（如本次有化验） | ~30秒 |
| 7 | 根据系统数据与患者交流，调整用药方案 | - |
| 8 | 在系统上更新HbA1c目标或用药计划（如有变化） | ~30秒 |
| 9 | 确认待处理的预警 | ~20秒 |

**时间效益**：相比传统翻纸质病历，系统将患者近期血糖管理状况一目了然地呈现，减少查阅时间约2-3分钟。

[图片：门诊场景操作流程示意图]

### 场景二：查房场景使用流程

**背景**：科室主任带领团队早晨查房，需要快速了解每位住院患者的血糖状况。

## 八、常见问题FAQ

### Q1: 为什么我看不到某些患者的数据？

系统中患者数据有严格的分层访问控制：
- **医生**：仅可查看分配给自己的患者（primary或consulting关系）
- **科室主任**：可查看本科室所有患者
- **管理员**：可查看所有患者基本信息，但临床数据仍需按权限访问

如遇确需查看但无权限的患者，请联系科室主任进行分配。

### Q2: 预警确认后还能再次查看吗？

可以。已确认的预警仍然保留在预警列表中，默认显示"未确认"预警，可通过筛选切换查看全部或已确认预警。

### Q3: 患者血糖趋势图的时间范围可以调整吗？

当前版本默认展示最近30天数据。如需更长周期数据，请联系系统管理员。

### Q4: AI解读的化验单结果可以直接作为诊断依据吗？

不可以。AI解读仅供辅助参考，最终诊断必须由您结合临床表现、体格检查和其他检查结果综合判断。请在患者详情页的"化验报告"区域查看AI解读，并结合原始化验单进行确认。

### Q5: 如何导出患者数据？

当前版本支持在患者详情页查看全部数据。批量数据导出功能请联系系统管理员通过备份恢复工具操作。

### Q6: 系统提示"令牌过期"怎么办？

系统JWT令牌有效期为30分钟。过期后，系统会自动跳转到登录页面。重新登录即可继续操作。

### Q7: 患者列表中的"血糖控制不佳"是如何定义的？

系统将最近一次血糖>10.0 mmol/L的患者标记为"血糖控制不佳"。这是一个粗筛指标，具体判断请结合患者的血糖趋势、HbA1c水平和个人目标。

### Q8: 可以在手机上使用吗？

系统前端采用响应式设计，可通过手机浏览器访问。同时患者端支持微信小程序。医生端目前主要为桌面浏览器（推荐Chrome/Edge最新版）优化。
