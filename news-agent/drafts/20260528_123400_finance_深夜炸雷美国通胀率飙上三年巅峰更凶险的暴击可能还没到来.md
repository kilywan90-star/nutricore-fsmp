# 深夜炸雷！美国通胀率飙上三年巅峰，更凶险的暴击可能还没到来？



刚刚，一份重磅数据让全球金融市场集体打了个寒颤。美国最新通胀率骤然攀升至三年以来的最高点，这不仅仅是一个数字的跳动，更可能是一连串连锁反应的开始。更让人揪心的是，多位分析师几乎异口同声地警告：情况在真正好转之前，恐怕还会变得更糟。

简而言之，你我的钱袋子，可能要面临又一轮来自大洋彼岸的考验。

这次通胀数据的恶化程度超出了绝大多数人的预期。剔除波动较大的食品和能源价格后，核心通胀数据同样顽固地粘在了高位，没有丝毫松动的迹象。数据显示，美国4月CPI同比涨幅猛然冲到了4.8%，这是自2023年初以来从未见过的高度，环比增速也达到了0.6%。美联储最看重的个人消费支出价格指数同样亮起红灯，核心PCE顽固地盘踞在3.5%上方，距离2%的政策目标越来越远。

物价的灼热感已经渗透到美国人生活的每个角落。从超市里的一盒鸡蛋、一斤牛肉，到房租、汽油、医疗保险，所有开支都在肉眼可见地上涨。密歇根大学的消费者信心调查显示，民众对未来一年的通胀预期已经飙升至4.5%，是近30个月来的最高水平。这种预期的自我强化，往往比实际通胀本身更让经济学家感到恐惧。

这一轮通胀反扑的元凶，是多股力量的共振绞杀。首先是关税政策的持续反噬。前两年加征的多轮关税，像是一颗颗延迟引爆的炸弹，如今正通过进口商品价格全部传导到了消费终端。一双普通的运动鞋价格涨了15%，一台中国组装的笔记本电脑价格跳涨超过20%，企业不得不把增加的成本转嫁给消费者。

供应链的再次绷紧则是火上浇油。红海航道危机远未结束，全球主要航运线路的运费依旧居高不下，一个40英尺集装箱从上海到洛杉矶的运价又悄然回到了8000美元上方。与此同时，美国墨西哥湾沿岸的极端天气频繁袭击，导致炼油厂停产，汽油价格在短短三周内就飙升了12%，加满一箱油多花掉十几美元，民众的怨气直接冲上了推特热搜。

劳动力市场的不降温更是让服务业通胀变成了脱缰的野马。职位空缺数重新站上900万大关，企业为了抢人不得不大幅加薪。休闲酒店、医疗保健、建筑业的工资同比涨幅都超过了5%。人力成本推高了理发、外食、房屋维修等一切服务的价格，而这类服务价格一旦涨上去，就很难再降回来。

面对如此局面，美联储的处境比走钢丝还要艰难。鲍威尔主席那句“higher for longer”正在变成冷酷的现实。就在数据公布后，利率期货市场对年内降息的押注瞬间蒸发，反而有超过60%的交易员开始定价9月份可能再加息25个基点。如果利率再次走高，美股的高估值科技板块将面临灭顶之灾，对利率敏感的商业地产和区域性银行也可能爆发新的地雷。

更深远的影响正在向全球蔓延。强势美元已经让日元跌到了160关口，欧元兑美元再次逼近平价，新兴市场国家则面临资本外流和债务偿还成本剧增的双重困境。这对我们国内来说，人民币汇率短期承压，进口原材料成本上升，稳增长的政策空间会受到一定程度的外部钳制。不过，中国完整的产业链和充足的政策工具箱，意味着我们抵御输入性通胀的能力远强于其它国家。

对于普通投资者而言，接下来几个月恐怕得握紧现金，减少对高估值风险资产的暴露。黄金、能源、农产品等实物资产可能会继续成为避风港。而对于背负着房贷、车贷的家庭来说，不要指望借贷成本短期内会下降，提前做好现金流规划比什么都重要。

历史一次次告诉我们，通胀的尾声往往最是凶险，因为它会逼迫央行做出最不情愿的抉择。美国这次能否有惊无险地跨过这道坎，全世界都在屏息等待。接下来的6月和7月两份CPI报告，将直接决定这个夏天是风暴前的宁静，还是新一轮狂风暴雨的开端。
