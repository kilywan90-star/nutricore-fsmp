# 深夜突发！美联储高官放话：通胀狙击战远未结束，降息梦碎？



就在市场集体押注美联储即将按下降息键的当口，堪萨斯城联储主席杰夫·施密德一盆冷水浇下来。他明确表态，抗击通胀的斗争“远未结束”，利率可能要在高位维持更长时间。这番话瞬间击溃了多头的心理防线，美股跳水，比特币闪跌，一片哀嚎。

施密德在一个线上经济论坛上直言，核心通胀指标仍在3%上方顽强徘徊，劳动力市场出人意料的强劲，薪资增速不减。他警告，如果现在就放松政策，通胀可能像脱缰野马一样再次失控，之前两年的加息代价就全白费了。这一警示并非危言耸听，回溯历史，上世纪70年代美联储正是在通胀初现缓和时过早降息，结果招致了1980年通胀率飙升至14.8%的灾难性后果，沃尔克最终不得不将联邦基金利率推高至20%才勉强驯服物价。与那时相比，当前5.25%到5.5%的利率水平远未到“非常紧缩”的程度，而核心PCE物价指数同比涨幅仍高达2.8%，距离2%的目标尚有明显距离，历史教训显然让施密德等人如履薄冰。

很多人对施密德可能还不熟悉。他2023年接棒堪萨斯城联储，一上任就以铁腕鹰派形象示人。在去年的几次公开讲话中，他就多次强调“宁可加息过度，也不能半途而废”。而本次表态，是他2026年以来最直白、最强硬的一次。同样值得留意的是，另一位鹰派代表人物、美联储理事鲍曼近期也重申，不排除进一步加息的可能性，并指出地缘政治动荡、财政赤字扩张以及住房成本粘性都可能令通胀重新抬头。这种高层鹰派的集体发声，显然不是孤立事件，更像是美联储内部对市场过于乐观预期的集中纠偏。

市场反应可以用“惨烈”来形容。言论传出半小时内，标普500指数期货直线下跌1.2%，纳斯达克综合指数一度抹去2%的涨幅。加密货币市场更是雪崩，比特币从68,500美元附近猛砸至64,200美元，24小时爆仓金额瞬间突破7.8亿美元，多单哀鸿遍野。这让人回想起2022年美联储启动激进加息时，比特币从6.9万美元历史高位一路暴跌至1.6万美元以下的血色记忆，而当时的高利率阴影如今似乎再度笼罩风险资产。

这背后是预期的剧烈反转。就在5月初，CME美联储观察工具还显示，9月降息的概率高达72%。施密德讲话后，这一数字缩水到34%。10年期美债收益率飙升15个基点，重回4.8%关口，美元指数也暴力拉升，重新站上106。利率期货市场甚至开始押注12月再度加息的可能性，极端悲观情绪正在快速蔓延。

为什么通胀这么顽固？施密德给出了自己的诊断：住房成本和服务价格就像两块牛皮糖，怎么也压不下去。医疗、保险、教育等服务领域的涨价势头丝毫不减，而业主等价租金指数还在不断上修。此外，能源价格受地缘因素干扰频繁波动，给核心通胀的回落增添了巨大阻力。事实上，美国劳工部最新数据显示，住房成本占CPI权重的三分之一以上，其同比涨幅仍高达5.7%，成为抗通胀的最大绊脚石。而服务通胀中，理发、汽车修理、宠物医疗等“劳动密集型”项目涨幅动辄超过6%，反映的是薪资增长的强劲传导。

更让人头疼的是就业数据。最新非农报告显示，新增就业岗位连续第8个月超出预期，失业率维持在3.6%的历史低位。工资同比增幅虽然从高峰回落，但仍然维持在4.3%，远高于与2%通胀目标相匹配的3%水平。施密德认为，这是需求依然过热的铁证。诺贝尔经济学奖得主保罗·克鲁格曼近日也撰文指出，当前劳动力市场的“过热”程度是过去20年少见的，如果参与率和生产率的改善不能及时抵消薪资压力，通胀将长期盘踞在3%一线，使美联储最后一步变得异常艰难。这一观点与施密德的担忧不谋而合，也进一步说明美联储内外的鹰派共识正在强化。

影响与展望方面，此次鹰派风暴绝不仅是短期价格波动这么简单。对于股市，科技成长股对利率高度敏感，纳斯达克指数的估值泡沫可能面临进一步挤压，而银行、能源等价值板块或许相对抗跌，但也难以独善其身。房地产市场更是直面冲击，30年期按揭利率已重回7.5%以上，购房成本升至13年来最高，新屋开工和成屋销售双双萎缩，地产链相关的建筑、家居零售板块前景黯淡。企业层面，高利率意味着借新还旧成本剧增，标普500成分股中，2024-2025年到期的公司债规模达到创纪录的2.1万亿美元，再融资压力可能引发信用风险上升，特别是中小企业和低评级发行人的违约率已经在攀升。

对于加密货币投资者，这无疑是一记重锤。高利率意味着资金成本高企，流动性退潮，风险资产首当其冲。短期来看，比特币正面临与2022年类似的宏观逆风，甚至有分析师喊出“重返5万”的悲观预测。但另一派则认为，若通胀最终变成长久顽疾，比特币的稀缺性叙事将重获青睐，成为下一个牛市发动机。不过这种判断需要极其苛刻的条件，即美联储政策彻底失效、法币信用出现裂缝，在目前美元强势的背景下，这一情境实现的概率仍然很低。

回归到美联储的棋局，施密德的放话等于给市场定了个调：别指望今年能痛快降息，甚至不排除再加一次。6月议息会议眼看就要召开，这份“鹰派惊喜”让所有人的神经都绷紧了。最新点阵图若显示年内降息次数从三次砍到一次，甚至完全消失，将进一步打压市场情绪。全球也会感受到冲击波，新兴市场资金外流压力加剧，美元借贷成本上升可能令部分脆弱经济体陷入货币危机。

对于普通投资者而言，幻想“水牛”归来已经不太现实。未来3到6个月，资产配置必须防御为王，现金为王。短期国债、货币基金以及黄金等避险资产可能跑赢风险资产，而权益投资则应转向现金流充裕、低杠杆的龙头防御股。别跟美联储作对这句话，此刻显得格外刺耳。你觉得年底前真的一次降息都不会有吗？欢迎在评论区吵一架，写下你的判断。
