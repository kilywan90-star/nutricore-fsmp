# 突发！城堡证券深夜警告：通胀反扑，美联储应立刻加息，降息梦彻底碎了？



全球市场刚准备庆祝降息，一盆冷水突然泼了下来。2026年5月26日晚间，顶级做市商城堡证券发布重磅报告，直言“通胀已成为首要风险”，并呼吁美联储“尽快转向加息”。这个结论，等于直接给当下还在幻想美联储年内降息的投资者，浇了个透心凉。

城堡证券在华尔街可不是普通角色，它掌控着全美约四分之一股票交易量，对流动性变化比美联储自己还敏感。这次它用词极其严厉，不是“继续观望”，也不是“保持限制性”，而是直接要求重启加息。报告发布后，纳斯达克期货应声急跌，2年期美债收益率瞬间飙升12个基点，市场反应之剧烈，如同惊弓之鸟。

为什么城堡证券突然变得如此鹰派？关键在通胀数据。上周公布的4月核心PCE物价指数意外回升至3.2%，打破了连续5个月的缓慢下行趋势。更麻烦的是，住房通胀分项重新加速，环比涨了0.6%，这是近一年来最高值。报告里特别点了“超级核心服务通胀”——剔除了住房的服务物价——同比仍高达4.5%，丝毫没有妥协的苗头。

城堡证券首席经济学家在报告中算了一笔账：如果美联储6月不紧急加息25个基点，按照当前工资增速和消费热度，三季度整体通胀很可能从目前的2.8%直接弹回3.5%以上。到那时，被迫加大加息幅度，经济硬着陆的风险反而更大。“早痛比晚痛好”，这是报告的潜台词。

一石激起千层浪。就在一个月前，市场定价还显示6月降息概率超过70%，彭博社调查的经济学家中位数预测也是年内降息两次。城堡证券这番表态，相当于把共识撕得粉碎。更有意思的是，报告特意指出，2026年初涌入市场的近8000亿美元货币基金，随时可能反手做空，将成为加速市场下跌的助燃剂。

历史总是惊人相似。2022年，正是因为美联储对通胀“暂时性”的误判，导致后来被迫连续四次加息75个基点，美股全年暴跌。城堡证券提醒，现在联储又站到了同样的十字路口：就业市场连续24个月新增岗位超20万，消费者信心指数回到92高位，信用卡消费数据没有丝毫降温迹象。这种情况下还想靠拖来解决问题，只会重蹈覆辙。

然而华尔街内部并非铁板一块。摩根大通刚在周一说，通胀反弹只是“噪音”，服务价格的滞后性调整即将体现，坚持认为9月会降息。高盛则相对中性，把首次降息预测从6月推迟到了12月，但更倾向于“维持不变”而非加息。城堡证券是第一个明确提出“必须加息”的主要机构，这种极端鹰派立场，让整个周末前的盘面充满火药味。

对普通散户来说，这意味着什么？如果美联储真被倒逼加息，首先崩的就是科技成长股。那些靠低利率讲故事、利润薄得可怜的公司，估值模型会瞬间崩塌。其次，房贷利率可能重新站上8%，刚刚回暖了一点的美国楼市又要被打回原形。再就是美元，美元指数已经因加息预期飙到107，新兴市场将面临新一轮资本外流压力。

当然，城堡证券的警告也可能是“喊话交易”。作为做市商，它在利率期货和债券市场持有大量头寸，提前放大风声引导市场预期并不稀奇。但过往记录显示，这家机构对流动性拐点的预判准确度相当高。2020年3月，它准确警告了美债闪崩；2024年，它在全球都在谈衰退时坚定看多，结果标普500当年涨了18%。这回，历史还会站它这边吗？

接下来的48小时非常关键。美联储理事沃勒将在本周五发表讲话，市场盯着他会否对加息松口。如果连一贯鸽派的沃勒都露出鹰派口风，那6月15日的议息会议可能直接飞出黑天鹅。毕竟，在抑制通胀和保护就业之间，鲍威尔说过无数次，“我们会毫不犹疑选择前者”。
