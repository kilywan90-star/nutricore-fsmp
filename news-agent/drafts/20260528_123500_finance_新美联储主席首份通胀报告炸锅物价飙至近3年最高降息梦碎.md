# 新美联储主席首份通胀报告炸锅！物价飙至近3年最高，降息梦碎？



就在刚刚，全球金融市场迎来一枚震撼弹。

新任美联储主席凯文·沃什上任后的第一份通胀成绩单正式公布，数据全线爆表——美国5月消费者价格指数（CPI）同比大涨4.2%，创下自2023年6月以来的最高纪录，远超市场预期的3.9%。更令人不安的是，剔除波动较大的食品和能源价格后，核心CPI同比攀升至4.4%，同样刷新近三年高点。

这份报告几乎宣告了连续两年的降息预期彻底破灭，更把沃什推到了风口浪尖。

历史总是惊人地相似。回望2022年，美国CPI一度飙升至9.1%的四十年来最高，随后美联储开启了一轮狂飙突进式的加息，将基准利率从接近零推高至5.5%。到2024年底，随着通胀逐步回落至3%附近，市场开始押注政策转向，降息呼声此起彼伏。然而，进入2025年，物价突然掉头向上：1月CPI同比3.8%，3月突破4%，5月直接冲破4.2%，形成一条陡峭的上升曲线。若将时间轴拉长，这一轮通胀反复的顽固程度，甚至超过了上世纪70年代石油危机后的通胀周期——当时通胀多次回落又反弹，最终迫使时任美联储主席沃尔克以极端紧缩政策才将其驯服。如今，相似的压力正落在沃什肩上。

“这绝不是一次性的数据扰动。”前美联储高级经济学家、现彼得森国际经济研究所研究员戴维·威尔考克斯在接受采访时直言，“过去几个月的核心服务价格，尤其是住房和保险费用，呈现出系统性的持续上涨，背后是劳动力市场紧张和供应链再度承压。”他警告，如果第二季度的通胀均值维持在4%上方，美联储不仅不能降息，反而应当认真考虑是否要进一步加息。就在报告发布后，高盛紧急修改预测，将首次降息时点从2025年9月推迟至2026年3月；摩根大通则干脆将年内降息预期全部清除，并指出“沃什时代的市场再定价才刚刚开始”。

具体到普通人的钱包，通胀的灼烧感更为真切。以芝加哥的简·罗德里格斯一家为例，她的月房租在2025年5月续租时上涨了12%，日用品账单较去年同期增加近18%，而她的时薪涨幅仅为4.5%。“我原本以为通胀已经过去了，但现在感觉比两年前更难存下钱。”简在接受当地媒体采访时说。她的处境并非个例：5月CPI报告中，住房指数同比涨幅达到6.1%，车险更是飙升21.9%，医疗保健、外出就餐等分项也全面上扬。这种宽基的物价压力，让中低收入家庭的实际购买力持续缩水，也为沃什领导下的美联储制造了巨大的政治敏感性。

对于沃什本人而言，这份通胀报告无异于一场就职大考。这位由前总统特朗普提名的经济学家，以偏鹰派的学术背景和对市场纪律的强调著称，但他在上任初期曾释放谨慎乐观信号，暗示通胀正“有序回落”。如今，数据给了他一记响亮的耳光。市场迅速做出反应：报告公布十分钟内，美股三大指数期货集体跳水，道琼斯期货一度跌逾600点；两年期美债收益率直线飙升18个基点至5.08%，创下年内新高；美元指数则暴力拉升，重回106关口。期权市场显示，交易员开始大举押注美联储在6月会议上“鹰派维持利率不变”并释放更强硬的前瞻指引。

影响与展望已变得更加严峻。从短期看，美联储6月议息会议几乎不可能提及降息，反而很可能将利率维持在高位更久，并在点阵图中削减甚至取消年内宽松的预期。中期来看，若夏季通胀继续黏着在4%附近，重新加息的概率将显著上升，联邦基金利率期货目前对9月加息25个基点的定价已从数据前的8%跃升至31%。长期而言，这种局面对全球资本流动构成巨大冲击：新兴市场面临货币贬值与资本外流双杀，以美元计价的大宗商品价格波动加剧，而背负高额浮动利率债务的企业和消费信贷将迎来新一轮坏账高峰。正如贝莱德固定收益首席投资官里克·里德所说：“这不是一场短跑，而是一场漫长的通胀消耗战。沃什必须在坚守鹰派立场和避免经济硬着陆之间走钢丝，留给他的容错空间已经极其狭窄。”

这场通胀复燃的烈火，正在烧掉市场上最后一丝降息幻想。凯文·沃什的考验，才刚刚开始。
