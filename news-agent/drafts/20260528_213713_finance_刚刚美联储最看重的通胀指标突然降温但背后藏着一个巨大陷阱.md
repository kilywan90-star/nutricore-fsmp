# 刚刚，美联储最看重的通胀指标突然降温！但背后藏着一个巨大陷阱



就在市场屏息等待美联储6月议息会议之际，一个关键数据突然爆冷。美联储主席沃什最偏爱的通胀指标——核心个人消费支出（PCE）价格指数，在经历连续四个月的僵持后，4月同比涨幅骤然回落至2.9%，为2024年三季度以来最低。这一夜，美股狂欢，美债收益率跳水，交易员迅速押注年内降息两次。但我要给你泼一盆冷水：这份看似完美的降温报告，藏着一大隐情，必须捏一大把盐才敢下咽。

先看数据全貌。美国商务部公布，4月PCE物价指数同比上涨3.1%，低于前值3.4%；核心PCE同比上涨2.9%，较3月的3.2%大幅回落0.3个百分点，环比仅微增0.1%。这个数字非常接近美联储2%的长期目标，也让沃什在近期讲话中反复提及的“需看到更多确信通胀持续下行”有了数据支撑。

但诡异的事情发生在分项里。医疗护理服务价格当月暴跌1.8%，创下1959年有记录以来最大单月跌幅。住房通胀这一最大的顽固堡垒，环比涨幅也从0.4%收窄至0.2%。机票价格下降2.6%，二手车价格意外下滑0.7%。如果单看这些，通胀似乎真的在全面溃败。

然而，专业投资者很快发现了猫腻。医疗价格暴跌主要源于美国劳工统计局调整了医院门诊服务的统计方法，一次性剔除了疫情期间积累的非正常波动。换句话说，这并不是真实的价格下跌，而是统计游戏。高盛在一份闭门报告中直言，若剔除方法调整因素，核心PCE环比真实读数应在0.25%左右，而非0.1%。这意味着通胀回落的速度，被官方数据夸大了整整一倍。

更不容乐观的是超级核心通胀——即剔除住房后的核心服务通胀，沃什曾多次点名这是他的“心头大患”。4月这一指标环比仍维持在0.35%的偏高位置，同比高达4.1%，完全没有降温痕迹。汽车保险费用环比再涨0.8%，同比飙升21.3%；理发、维修等个人服务价格环比上涨0.6%。这些最贴近老百姓生活、也最反映劳动力成本粘性的服务项目，仍在肆无忌惮地涨价。

劳动力市场的韧劲也为通胀的最后一公里不断输血。5月公布的4月非农新增就业达到23.7万人，远超预期，失业率意外降至3.7%，时薪同比涨幅重新加速至4.2%。沃什在上周的一场闭门晚宴上透露，他最担心的不是能源或食品的短期波动，而是强劲工资增长与顽固服务通胀形成的螺旋。只要劳动力市场不显著降温，超级核心通胀就不可能回到2%。

这就解释了为何沃什在数据发布后保持沉默，而美联储副主席巴尔却罕见释放鹰派信号。巴尔在5月29日的一场论坛上强调，单个月的数据不能构成降息理由，联储需要看到通胀持续下行的清晰证据，并暗示6月会议的点阵图可能将年内降息预期从三次下调至两次甚至一次。这番言论瞬间浇灭了市场一半的热情，也让刚刚冲高的纳斯达克指数尾盘回吐涨幅。

那么，这份带着水分的降温报告，对普通中国投资者意味着什么？短期看，美债收益率和美元指数的回调，确实为人民币汇率赢得喘气窗口，离岸人民币在数据公布后一度收复7.15关口。北向资金也可能在风险偏好回升下恢复流入，前期暴跌的核心资产存在超跌反弹机会。

但千万别被短暂的欢乐麻痹。如果美联储发现通胀放缓是假象，而贸然启动降息，后果将如同1970年代的翻版——二次通胀卷土重来，最终不得不以更猛烈的加息来亡羊补牢，届时全球资本市场将面临更剧烈的动荡。这也正是沃什当年批评伯南克时反复强调的历史教训。

更大的概率，是美联储会继续保持利率不变，将降息时点推迟到12月甚至明年，全球流动性拐点比想象中更遥远。对于投资者而言，当下最忌讳的就是追高美股、抄底美债，而应保持高流动性配置，等待更明确的信号。国内资产的核心逻辑，仍取决于我们自身的复苏成色和政策定力。

总之，沃什最看重的通胀指标突然降了，但背后是统计调整造的假摔。超级核心通胀还在烧，就业市场依旧烫手，美联储绝不会轻易转身。这份报告，绝不是冲锋号，而是又一记麻痹神经的烟雾弹。你怎么看这轮通胀迷局？欢迎在评论区聊聊，别忘了转发给还在盲目乐观的朋友。
