| 禁用/慎用 | 说明 |

## 第二章 政务领域专属禁用词与规范

**来源：** 国务院办公厅秘书局通知、各级党政机关公文规范、公文语言"十戒"等。

### 2.1 公文格式规范（依据 GB/T 9704-2012）

| 项目 | 规范要求 |
|------|---------|
| 标题字体 | 方正小标宋简体，二号 |
| 正文字体 | 仿宋_GB2312，三号 |
| 一级标题 | 黑体，三号 |
| 二级标题 | 楷体_GB2312，三号 |
| 行距 | 28磅（固定值） |
| 页边距 | 上37mm、下35mm、左28mm、右26mm |
| 发文字号 | 正确格式：XX发〔2026〕X号（使用六角括号） |
| 版记 | 分隔线+抄送机关+印发机关+印发日期 |

### 2.2 公文语言规范"十戒"

| 戒条 | 说明 | 典型错误 |
|------|------|---------|
| **戒不准** | 数据、时间、人物、事件必须准确 | "大概""可能""差不多""也许" |
| **戒歧义** | 表述无歧义 | "宣贯"（宣传贯彻的违规简称） |
| **戒不庄** | 语言庄重持重 | 口语化表达 |
| **戒浮华** | 避免过度修辞 | 大量排比、夸张、比喻 |
| **戒繁琐** | 开门见山，惜墨如金 | 冗长铺垫 |
| **戒跟风** | 不随意使用网络语言 | "给力""相当"等 |
| **戒俗语** | 用规范书面语言 | 方言土语 |
| **戒客套** | 上行文避免过分谦恭 | 过度自谦措辞 |
| **戒修饰** | 慎用程度副词 | "高、大、全、满"等 |
| **戒典故** | 不过度引经据典 | 卖弄学识的典故 |

### 2.3 公文字母词使用规范

**依据：** 国办秘函〔2010〕14号

- 公文一般不得使用字母词（如GDP、CPI、WTO等）
- 确需使用时，首次出现必须括注汉语译名
- 示例："GDP（国内生产总值）"

### 2.4 政务新闻宣传额外规范

| 禁用/慎用场景 | 说明 |
|-------------|------|
| 会议报道称"县长做指示" | 上级对下级部署工作才称"指示"，同级用"讲话" |
| 工作报道夸大成绩 | 慎用"历史性突破""前所未有""空前" |
| 领导活动过度报道 | 遵循中央八项规定关于新闻报道的要求 |
| 突发事件报道 | 以权威发布为准，不擅自定性、定责 |

## 第三章 医疗领域专属禁用词与规范

**来源：** 《中华人民共和国广告法》《医疗广告管理办法》《互联网广告管理办法》及各地市场监管与卫健部门公告。

### 3.1 《广告法》第十六条 — 医疗广告核心禁词

| 类别 | 禁用词/短语 |
|------|-----------|
| **功效断言** | 根治、包治百病、药到病除、一针见效、永不复发、彻底治愈、斩草除根 |
| **安全断言** | 安全无副作用、无毒无害、天然无刺激、放心使用 |
| **效果保证** | 治愈率达X%、有效率X%、X天病痛消失、无效退款、保证治愈 |
| **比较贬低** | 比其他医院先进、别人治不好的我们治、指定XX医院、最好的选择 |
| **代言推荐** | 患者证明、专家推荐、医生推荐、XX体验官、代言人（包括变相代言） |
| **涉及技术** | 干细胞疗法、免疫细胞治疗（未经审批的） |
| **疾病名称（非医疗广告场景）** | 不得以疾病名称为切入点做广告 |

### 3.2 《广告法》第九条 — 绝对化用语

> "国家级""最高级""最佳""顶级""极品""第一品牌""领导品牌""独家""首创""独一无二""绝无仅有""万能"等。

### 3.3 《医疗广告管理办法》第七条 — 禁止内容

- 涉及**医疗技术、诊疗方法、疾病名称、药物**
- 保证治愈或**隐含保证治愈**
- 宣传**治愈率、有效率**等诊疗效果
- 利用**患者、卫生技术人员、科研机构**名义/形象作证明
- 贬低他人
- 使用**解放军和武警部队**名义

### 3.4 医疗广告法定内容（《医疗广告管理办法》第6条）

医疗广告内容**仅限以下8项**，超出即违规：

1. 医疗机构第一名称
2. 地址
3. 所有制形式
4. 医疗机构类别
5. 诊疗科目
6. 床位数
7. 接诊时间
8. 联系电话

### 3.5 医院新闻稿/科普的合规红线

| 红线 | 说明 |
|------|------|
| 禁止以新闻/科普形式变相发布广告 | 《广告法》第十九条 |
| 科普内容不得出现联系方式 | 地址、电话、二维码、购物链接等 |
| 人物专访可出现机构名称 | 但不得含地址、电话等广告内容 |
| 宣传三原则 | **说事实，不说评价；讲服务，不讲疗效；做公益，不搞营销** |

### 3.6 医疗宣传常见禁用词清单

| 类别 | 禁用词 |
|------|--------|
| **疗效类** | 根治、治愈、痊愈、根除、去根、永不复发、永不反弹、斩草除根 |
| **速率类** | 一针见效、三天见效、立竿见影、即刻见效、马上就好 |
| **安全类** | 绝对安全、零风险、无任何副作用、纯天然无害 |
| **比较类** | 最好、最先进、第一、领先、超过、好于、优于 |
| **承诺类** | 包治、保证治好、无效退款、签约治疗 |
| **夸大类** | 奇迹、神奇、神效、奇效、特效、秘方、祖传、宫廷 |
| **恐吓类** | 不治将导致XX严重后果、错过就是终身遗憾 |
| **伪科学类** | 排毒、祛湿、打通经络、酸碱体质、清除自由基（除有循证依据外） |

### 3.7 非医疗行业误用医疗术语（《广告法》第十七条）

> 非药品/医疗器械/医疗广告，**禁止使用医疗用语**：
> - 美容院禁用"中医调理""活血化瘀""经络疏通"

## 第六章 未成年人保护与新修订《国家通用语言文字法》领域

**来源：** 《可能影响未成年人身心健康的网络信息分类办法》（2026年3月1日施行，网信办、公安部、广电总局等部门联合发布）、新修订《中华人民共和国国家通用语言文字法》（2026年1月1日施行）、中央网信办未成年人网络保护专项行动系列文件。

> **说明：** 此章节属于近年新增重点监管领域，建议作为独立词库子模块纳入审核系统，与第一章通用禁用词库联动。

### 6.1 未成年人网络信息内容禁用规范

《可能影响未成年人身心健康的网络信息分类办法》自2026年3月1日起施行，是未成年人网络保护领域的重要依据。以下内容在涉及未成年人的网络产品和服务中严格禁用：

| 类别 | 禁用内容/行为 | 说明 |
|------|-------------|------|
| **性暗示与软色情** | 带有性暗示、性挑逗等易产生性联想的内容 | 包括文字、图片、音视频等形式 |
| **网络暴力** | 指责嘲讽、贬低歧视、侮辱谩骂等涉网络暴力不良信息 | 严禁制造网络戾气 |
| **诱导消费** | 诱导未成年人进行充值、打赏等非理性消费行为 | 直播打赏、游戏充值等场景 |
| **不良生活方式** | 宣扬未成年人抽烟（含电子烟）、饮酒、暴饮暴食、不合理使用或滥用药物等 | 包括任何形式的倡导或美化 |
| **不良网络用语** | 通过谐音梗、缩写词、拆解字、图文结合等形式传播不良网络用语 | 如"SB""TMD"等变体形式 |
| **煽动对立冲突** | 煽动人群歧视、地域歧视、对立冲突 | 包括民族、地域、性别等维度 |
| **价值观误导** | 可能对未成年人价值观造成负面影响的信息 | 宣扬拜金主义、享乐主义等 |

### 6.2 《国家通用语言文字法》修订带来的禁用规范

2025年12月27日，第十四届全国人民代表大会常务委员会第十九次会议表决通过新修订的《中华人民共和国国家通用语言文字法》，自2026年1月1日起施行。这是该法颁布25年来首次修订，新增对网络语言的规范要求。

**新增禁用情形：**

| 种类 | 禁用/不良行为 | 规范要求 |
|------|-------------|---------|
| **网络语言文字** | 暴力类、贬义类等非规范语言使用 | 教育部门会同网信部门出台网络语言文字规范使用专门文件 |
| **网络视听节目** | 用语用字不规范 | 新增对网络视听节目、网络出版物的规范要求 |
| **互联网信息平台** | 用语用字不规范 | 政府主办或提供社会公共服务的互联网信息平台须规范用语用字 |
| **网络空间用语** | 语言文字不规范、不文明 | 中央网信办联合教育部开展"清朗·规范网络语言文字使用"专项行动 |

### 6.3 未成年人保护场景下的特殊禁用

| 禁用/禁止行为 | 规范要求 |
|-------------|---------|
| 面向未成年人的产品和服务中传播可能影响未成年人身心健康的网络信息 | 任何组织和个人不得制作、复制、发布、传播 |
| 首页首屏、弹窗、热搜、榜单、精选等高曝光环节呈现可能影响未成年人身心健康的网络信息 | 禁止呈现，零容忍 |
| 专门面向未成年人的网络产品 | 对可能影响未成年人身心健康的网络信息零容忍 |
| 通过技术手段向未成年人推送风险信息 | 平台须建立安全管理制度与技术防护措施，杜绝推送 |

## 第七章 AI生成内容领域禁用词与规范

**来源：** 《人工智能生成合成内容标识办法》（四部门联合发布，2025年9月1日施行，国信办通字〔2025〕2号）、《互联网信息服务深度合成管理规定》、强制性国家标准 GB 45438-2025《网络安全技术 人工智能生成合成内容标识方法》。

> **说明：** 此章节直接关联"星原"产品的合规性——产品本身属于AI生成内容服务，必须满足标识要求。

### 7.1 AI生成合成内容标识缺失 — 禁止发布

《人工智能生成合成内容标识办法》由国务院网信办、工业和信息化部、公安部、国家广电总局等四部门联合发布，配套强制性国家标准 GB 45438-2025 同时出台，统一于2025年9月1日起正式施行。

**显式标识缺失 — 禁止发布：**

| 禁用情形 | 规范要求 |
|---------|---------|
| 无显式标识的AI生成合成文本 | 应在文本起始、末尾或中间添加文字提示或通用符号提示 |
| 无显式标识的AI生成合成音频 | 应在音频起始、末尾或中间添加语音提示或音频节奏提示 |
| 无显式标识的AI生成合成图片 | 应在图片适当位置添加显著提示标识 |
| 无显式标识的AI生成合成视频 | 应在视频起始画面和周边添加显著提示标识 |
| 无显式标识的AI生成合成虚拟场景 | 应在起始画面添加显著提示标识 |
| 下载/复制/导出的AI内容不含显式标识 | 应当确保文件中含有满足要求的显式标识 |

**隐式标识缺失 — 禁止发布：**

> AI生成合成内容的文件元数据中须添加隐式标识，包含生成合成内容属性信息、服务提供者名称或编码、内容编号等制作要素信息。

### 7.2 恶意破坏标识的行为 — 严禁

| 禁用行为 | 依据 | 说明 |
|---------|------|------|
| 恶意删除标识 | 《标识办法》第十九条 | 不得恶意删除本办法规定的生成合成内容标识 |
| 篡改标识 | 同上 | 不得篡改生成合成内容标识 |
| 伪造标识 | 同上 | 不得伪造生成合成内容标识 |
| 隐匿标识 | 同上 | 不得隐匿生成合成内容标识 |
| 为上述行为提供工具或服务 | 同上 | 不得为他人恶意删除、篡改、伪造、隐匿标识提供工具或服务 |
| 不正当标识手段损害他人合法权益 | 同上 | 不得通过不正当标识手段损害他人合法权益 |

### 7.3 AI生成短视频内容标注 — 6类必选标签

根据中央网信办关于规范短视频内容标注的部署，网络平台须为用户提供6类"必选标签"，AI生成内容发布时不得省略标注：

| 必选标签类型 | 说明 |
|-------------|------|
| 含有虚构演绎内容 | AI辅助创作但存在虚构成分 |
| 含有AI生成内容 | 全部或主要由AI生成 |
| 含有营销信息 | AI生成但包含商业推广信息 |
| 内容为转载 | AI生成内容但素材来源为转载 |
| 内容为个人观点 | AI辅助表达的个体观点 |
| 无需标注 | 仅适用于完全真实生活记录 |

**特殊禁用：** AI生成式广告中，未经权利人同意，不得利用AI生成并使用他人形象；以AI虚构的人物形象为产品、服务进行推荐、证明，须对AI内容作出提示。

### 7.4 AI内容深度合成安全规范

依据《互联网信息服务深度合成管理规定》第十六条、第十七条：

| 条目 | 规范要求 |
|------|---------|
| 内容安全 | 不得制作、复制、发布、传播法律禁止的信息内容 |
| 深度合成标识 | 可能导致公众混淆误认的深度合成内容，须显著标识 |
| 用户身份核验 | 须对使用者真实身份信息进行核验 |
| 安全评估备案 | 具有舆论属性或社会动员能力的深度合成服务，须进行安全评估并备案 |

> **对"星原"的启示：** 所有AI生成的稿件，必须在文末或适当位置添加"本文由AI辅助生成，经人工审核"标识；稿件元数据中须嵌入生成属性信息。此合规要求应内置到系统导出/发布流程中，不可遗漏。

## 第八章 网络主播与自媒体账号领域禁用词与规范

**来源：** 中央网信办《关于规范网络名人账号行为管理的通知》（2025年12月25日发布）、《网络直播带货广告合规提示》（各地，2025年发布）、八部门未成年人网络保护办法等。

### 8.1 网络名人账号负面清单 — 13类禁用行为

中央网信办秘书局于2025年12月25日发布《关于规范网络名人账号行为管理的通知》，明确了网络名人账号行为负面清单，共13类禁用行为。此清单适用于粉丝数量大、社会关注度高的网络名人账号，各网站平台须对照清单落实管理责任。

| 序号 | 禁用行为类别 | 具体表现 |
|------|------------|---------|
| 1 | **传播低俗内容** | 故意不规范使用语言文字，编造黑话烂梗，使用污言秽语、粗鄙表达，以打擦边球、使用暗语等方式传播软色情、性暗示等低俗媚俗内容 |
| 2 | **宣扬不良价值导向** | 编造话语体系，宣扬"躺平摆烂""颓废厌世""炫富拜金"等违背社会主义核心价值观的不良思想，调侃戏谑主流价值，制造贩卖焦虑 |
| 3 | **打造审丑不良人设** | 打造恶搞浮夸、装疯卖傻、以丑为美、自我矮化等违背公序良俗的人设，恶意营销"前科人员""黑社会"等身份 |
| 4 | **传播不实信息** | 杜撰经历、仿冒身份，传播伪科普、伪史学等伪知识，虚构夸大产品、服务效果，未作标注编造剧情、摆拍演绎 |
