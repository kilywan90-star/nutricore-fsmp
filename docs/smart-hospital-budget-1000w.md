# 县级智慧医院信息化建设项目 — 1000万预算建设清单

> **编制依据：**
> - 国家卫健委《智慧医疗分级评价方法及标准（2025版）》（整合电子病历评级+互联互通测评）
> - 国家卫健委《医院智慧服务分级评估标准体系（试行）》
> - 国家卫健委《医院智慧管理分级评估标准体系（试行）》
> - 国家卫健委《电子病历系统应用水平分级评价标准》
>
> **参考案例：**
> - 丘北县中医医院（2025年，1000万，目标电子病历四级）
> - 永福县医院（2025年，1000万，目标电子病历四级+、互联互通四级乙等、智慧服务二级）
>
> **建设目标：** 电子病历≥4级 + 互联互通≥四乙 + 智慧服务≥2级 + 智慧管理≥2级
> **医院规模：** 县级二甲，500-800张床，年门诊量30-50万
> **预算总额：** ¥10,000,000.00（壹仟万元整）

## 八、关键提醒

1. **1000 万做单体医院智慧化是标准预算。** 丘北、永福两个真实案例都是这个数，不是拍脑袋。

2. **核心必须打在评级上。** 电子病历四级 + 互联互通四乙是硬指标，钱首先保证这两个过。智慧服务、智慧管理是锦上添花，可以二期做。

3. **信创是底线不是加分项。** 服务器 CPU 选鲲鹏/飞腾，OS 选麒麟，数据库选人大金仓/达梦。招标文件里没有信创方案直接废标。

4. **集成平台 ESB 是第一个要上的。** 破了信息孤岛，后面的 CDR/闭环管理/驾驶舱才跑得起来。

5. **评级辅导服务费别省。** 电子病历四级 + 互联互通四乙的申报材料、模拟测评、现场查验，靠医院信息科自己搞不定。预算里有 27 万是专门留给这个的。
