## 1. 产品概述与定位

### 1.1 产品定位

弦序视频创作平台是专为本地生活服务商家打造的 AI 短视频营销全链路解决方案。基于 Seedance 多模型引擎，解决商家"不会拍、拍不好、成本高、效率低"的核心痛点，实现"3 分钟生成 10 条高质量引流视频，单条成本低至 3.61 元"，帮助商家通过短视频获取同城流量，提升到店转化率。

### 1.2 核心价值主张

| 价值维度 | 具体指标 | 对比基准 |
|---------|---------|---------|
| 极致成本 | 平均 3.61 元/条 | 传统外包拍摄 500-2000 元/条，节省 95%+ |
| 超高效率 | 94% 生成成功率，3 任务并行 | 传统制作 1-3 天/条 |
| 本地化深度 | 四川话/粤语/东北话等方言口播 | 竞品以普通话为主 |
| 全链路闭环 | 文案→制作→分发→追踪一站式 | 竞品多为单点工具 |
| 千企千面 | 每商户独立 AI 模型实例 | 竞品为通用模型 |

#### DEMO 验证数据

- 已为用户累计节省 28,600 元（对比传统外包）
- 成都某麻辣烫店：30 条视频 → 50 万+播放 → 到店客流提升 40% → 团购核销增加 120 单
- 重庆某奶茶店：50 条视频 × 10 账号矩阵 → 100 万+播放 → 成为当地网红店

### 1.3 竞品分析与差异化优势

#### 战略差异化定位

1. **闭环优势**：从视频生成到平台分发到到店转化追踪，全链路闭环（竞品多为单点工具）
2. **千企千面**：每商户独立 AI 模型，学习其品牌调性、产品特点、文案偏好（竞品为通用模型）
3. **成本领先**：通过批量处理和模型调度优化，实现 3.61 元/条的极致成本
4. **本地化壁垒**：方言口播 + 本地场景模板 + 本地平台深度集成，形成区域竞争优势

## 2. 市场分析与竞品对标

### 2.1 市场规模

- 中国本地生活服务市场规模：2025 年约 5.6 万亿元，年增速 15%+
- 抖音本地生活 GMV：2025 年超 6000 亿元，商家短视频营销渗透率不足 30%
- AI 视频生成市场规模：2025 年约 80 亿元，预计 2028 年达 500 亿元
- 目标市场（西南地区餐饮+美业商家）：约 200 万商户

### 2.2 竞争格局

```
                    高
                    ↑
  内容质量/专业度    │
                    │  即梦 AI         可灵 AI
                    │  (高画质, 无分发)  (长视频, 无分发)
                    │
                    │      弦序视频 (目标定位)
                    │      ★ 全链路+千企千面+极致性价比
                    │
                    │  花儿朵朵 AI      沃创 AI
                    │  (深耕本地, 有分发) (电商闭环, 有分发)
                    │
                    │  剪映商家版
                    │  (免费, 通用)
                    │
                    └──────────────────────────→ 高
                        本地生活场景深度/分发能力
```

### 2.3 全球 AI 视频赛道趋势

| 趋势 | 说明 | 对本产品的影响 |
|------|------|--------------|
| Sora 关停 (2026.3) | OpenAI 因成本过高关停独立产品，功能并入 ChatGPT | 验证"独立 AI 视频工具难以持续"判断，全链路闭环是存活关键 |
| 实时生成崛起 | Pika 2.5 (40-68s/gen)、Seedance 2.0 fast (10-15s) | 批量生成性能是核心竞争维度 |
| 数字人标配化 | 可灵/剪映/花儿朵朵均已支持数字人 | 数字人已成 table stakes，MVP 后必须快速跟进 |
| 合规监管趋严 | 中国 2025.9 AI 标识双标签制度，全球多地跟进 | 合规能力是入场券，非可选项 |
| 垂直化生存 | 通用工具难盈利，垂直场景（电商/本地生活/教育）是出路 | 坚持本地生活垂直定位 |

## 5. 产品目标与成功度量 (OKR)

### 5.1 产品北极星指标

**每周通过平台发布并获得 ≥100 次播放的商户数**

此指标同时衡量：商户活跃（使用平台生成并发布视频）和内容有效（视频获得播放），是"商户获得价值"的最佳代理指标。

#### REQ-VIDEO-001 [Must] AI 视频生成 - 模板化基础生成

**用户故事**：作为本地餐饮商户老板，我希望上传几张菜品照片和一段促销文案，系统就能自动生成一条抖音风格的营销视频，这样我不需要任何拍摄或剪辑技能就能保持日更。

**验收标准**：

```
Scenario 1: 基础视频生成成功 (Happy Path)
  Given: 商户已登录, 已选择"餐饮-火锅"行业模板
    And: 商户上传 >= 3 张菜品照片 (JPG/PNG)
    And: 商户填写促销标题 "今日特惠", 选择视频时长 15 秒
  When: 商户点击 "生成视频"
  Then:
    - 系统在 60 秒内返回视频预览 (720p, H.264, 30fps)
    - 视频包含: 片头动效 + 菜品轮播 + AI 配音 + 字幕 + 片尾联系方式
    - 商户可播放预览, 点击 "确认" 进入发布流程, 点击 "重新生成" 调整
    - 生成成功, 任务状态为 "已完成"

Scenario 2: 素材不足 (Graceful Degradation)
  Given: 商户仅上传 1 张照片
  When: 商户点击 "生成视频"
  Then:
    - 系统显示提示: "建议上传 3-9 张照片以获得最佳效果, 当前仅 1 张可能影响视频丰富度"
    - 允许商户继续生成 (非阻断), 但自动补充行业通用素材占位
    - 生成视频中右下角轻提示 "素材较少, 效果可能不佳"

Scenario 3: 生成失败恢复 (Error Recovery)
  Given: AI 服务返回错误 (超时/模型不可用)
  When: 视频生成中断
  Then:
    - 系统自动重试最多 3 次, 间隔 2/4/8 秒
    - 3 次均失败后, 任务状态标记为 "失败"
    - 通知商户 "生成失败, 请稍后重试" [错误码: E-VIDEO-GEN-001]
    - 商户的素材和文案已保存, 不需要重新上传

Scenario 4: 模型自动选择
  Given: 商户未手动指定模型版本, 文案为普通促销内容
  When: 商户点击 "生成视频"
  Then:
    - 系统默认使用 Seedance 2.0 fast 模型 (性价比优先)
    - 若商户选择了 "高质量" 开关, 系统使用 Seedance 2.0
    - 任务详情中展示使用的模型版本和消耗算力

Scenario 5: 配额不足
  Given: 商户本月视频生成额度已用完 (免费版: 10 条/月)
  When: 商户点击 "生成视频"
  Then:
    - 系统显示 "本月生成额度已用完 (10/10)"
    - 提供升级入口: "升级至基础版, 每月 100 条" [定价页链接]
    - 已上传素材和文案保留, 升级后可直接继续生成
```

### 7.3 内部 API 设计原则

- 所有内部 API 版本化: `/api/v1/...`

  ```json
  }
  ```
- 所有 API 返回 `request_id` 用于追踪和客服查询
- P95 响应时间 < 500ms (非视频生成接口), P99 < 2000ms

## 9. 内容合规与安全体系

### 9.1 监管要求基线

| 法规/规范 | 生效日期 | 核心要求 | 对本产品的影响 |
|---------|---------|---------|--------------|
| 《互联网信息服务深度合成管理规定》 | 2023.1.10 | AI 生成内容需显著标识, 不得用于违法活动 | AI 标识水印为必须项 |
| 《生成式人工智能服务管理暂行办法》 | 2023.8.15 | 生成内容需遵守法律法规, 尊重知识产权, 保护个人信息 | 内容审核 + 广告法检测为必须项 |
| 《人工智能生成合成内容标识办法》 | 2025.9.1 | **双标签制度**: 显式标识 (可见水印) + 隐式标识 (嵌入元数据) | 合规管线必须内置 |
| 《互联网广告管理办法》 | 2023.5.1 | 广告需显著标明 "广告", 禁止绝对化用语 | 广告法检测模块必须上线 |
| 抖音/快手 AI 内容标识规范 | 已生效 | 平台级 AI 内容标识要求, 未标识内容将被下架 | 分发前必须完成平台级标识 |

### 9.2 合规检测管线

```
输入素材/文案
  │
  ├──→ [1] 违禁内容扫描 (规则引擎)
  │     检测: 涉政/色情/暴力/恐怖/赌博/毒品
  │     拦截率目标: 80% 违规内容在此层拦截
  │     延迟: < 1 秒
  │
  ├──→ [2] 广告法合规检测 (规则引擎 + NLP 模型)
  │     检测: 绝对化用语 (最好/第一/唯一/顶级...)
  │           虚假宣传 (疗效承诺/收益承诺...)
  │           敏感行业词 (金融/医疗/教育...)
  │     拦截率目标: 90% 违规文案在此层拦截
  │     延迟: < 1 秒
  │
  ├──→ [3] 视觉内容审核 (视觉模型)
  │     检测: 低俗画面/暴力血腥/人脸冒用/虚假产品效果
  │     拦截率目标: 剩余违规内容的 75% 在此层拦截
  │     延迟: < 3 秒
  │
  ├──→ [4] AI 标识注入 (强制)
  │     显式水印: 视频边角 "AI 生成" 标识, 面积 ≥ 画面 5%, 持续 ≥ 2 秒
  │     隐式元数据: MP4 metadata 注入 ai_generated=1, model_name, merchant_id, gen_timestamp
  │     数字人特定: synthetic_face=1
  │     不可逆: 标识注入后无法去除 (至少增加去除成本)
  │
  └──→ [5] 平台格式合规校验
        抖音: 9:16, 720p+, H.264, 文件 < 4GB
        检查标题/话题是否含违规词
        输出: 通过 / 拦截 + 原因
```

### 9.3 审核策略与 SLA

| 审核层级 | 覆盖比例 | 响应时间 (SLA) | 处理方式 |
|---------|:---:|:---:|---------|
| 机器审核 (规则引擎) | 100% | < 1 秒 | 低风险: 放行 <br>中风险: 标记警告但放行 <br>高风险: 拦截并通知商户 |
| 机器审核 (视觉模型) | 100% | < 3 秒 | 辅助规则引擎, 提高拦截准确率 |
| 人工复审 | 5-10% (高风险+随机抽检) | < 15 分钟 (工作日 9:00-21:00) <br>< 60 分钟 (夜间) | 高风险内容强制人工审核 <br>随机抽检 5% 用于质量评估 |
| 发布后抽检 | 5% | < 24 小时 | 发现违规 → 紧急撤回 → 通知商户修改 |
| 紧急撤回 | 按需 | < 10 秒 (全平台同步) | 接到平台下架通知或用户投诉 → 立即撤回+冻结商户发布权限 |

### 9.4 合规指标

| 指标 | 目标值 | 测量方法 |
|------|--------|---------|
| 违规内容拦截率 (机审) | ≥ 95% | 机审拦截数 / (机审拦截数 + 人审发现违规数) |
| 误拦率 (正常内容被拦截) | < 3% | 人工抽检误拦数 / 总拦截数 |
| 逃逸率 (违规内容通过审核) | < 1% | 被平台下架或用户投诉的违规数 / 总发布数 |
| AI 标识覆盖率 | 100% | 注入了双标签的视频数 / 总生成视频数 |
| 人工审核超时率 | < 5% | 超时任务数 / 总人工审核任务数 |
| 紧急撤回完成时间 | P95 < 10 秒 | 撤回指令发出 → 全平台确认删除 |

| 日均视频生成量 | ≥ 5000 条 | MVP 阶段 |
| 峰值 QPS | ≥ 500 | 晚间 19:00-22:00 高峰 |
| 弹性扩容触发 | CPU > 70% 或 队列积压 > 200 | 自动水平扩展 |

### 10.3 安全需求

| 需求 | 实现方式 |
|------|---------|
| 商户认证 | 手机号 + 短信验证码 (支持微信一键登录 V1.1) |
| 数据传输加密 | TLS 1.3 全链路加密 |
| 数据存储加密 | AES-256 静态加密 (数据库 + 文件存储) |
| 商户数据隔离 | 租户 ID 逻辑隔离, 所有查询强制带 tenant_id 过滤 |
| 防重放攻击 | API 请求携带 timestamp + nonce, 有效期 5 分钟 |
| 敏感操作二次验证 | 删除视频/解绑账号/修改手机号 → 短信验证码确认 |
| 子账号权限控制 | RBAC: 管理员 (全部权限) / 编辑者 (生成+发布) / 查看者 (只看数据) |
| 日志审计 | 所有操作日志保留 ≥ 6 个月 (合规要求) |
| 数据备份 | 每日全量备份 + 实时 binlog 增量, 保留 30 天 |

### 10.4 可用性需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 系统可用性 | ≥ 99.5% (不含计划维护) | 月度统计 |
| 计划内停机 | ≤ 4 小时/月 | 凌晨 2:00-6:00 窗口 |
| 故障恢复时间 (RTO) | ≤ 30 分钟 | 从故障发生到服务恢复 |
| 数据恢复点 (RPO) | ≤ 5 分钟 | 最大数据丢失窗口 |

## 14. 风险矩阵与回滚标准

### 14.1 技术风险

| 风险 | 发生概率 | 影响 | 触发条件 | 回滚动作 | 恢复条件 |
|------|:---:|:---:|---------|---------|---------|
| AI 生成质量下降 | 中 | 高 | 商户差评率 > 5% 持续 24h <br>或生成后删除率 > 20% 持续 24h | 切换至上一稳定模型版本, 通知模型供应商 | 新模型差评率 < 2% 持续 48h |
| 模型服务不可用 | 中 | 高 | 生成成功率 < 90% 持续 10min | 自动切换至降级模型 (Seedance 1.5), 通知运维 | 主模型成功率恢复 > 95% 持续 15min |
| 视频分发 API 故障 | 中 | 中 | 分发成功率 < 80% 持续 5min | 暂停该平台分发, 队列缓存待发布视频 | 分发成功率恢复 > 95% 持续 10min |
| 系统过载/队列积压 | 中 | 中 | 队列积压 > 500 任务 或 P95 等待 > 10min | 自动弹性扩容, 暂缓低优先级任务 | 积压 < 200 且 P95 等待 < 5min |
| 数据库故障 | 低 | 高 | 主库不可达 > 30s | 自动切换至只读副本 (服务降级为只读模式), 触发主从切换 | 主库恢复 + 数据一致性校验通过 |
| 存储故障 | 低 | 高 | 文件存储不可用 > 30s | 切换至备用存储节点, 暂停新素材上传 | 存储恢复 + 完整性校验通过 |

### 14.2 市场与业务风险

| 风险 | 发生概率 | 影响 | 触发条件 | 应对措施 |
|------|:---:|:---:|---------|---------|
| 竞品大幅降价/免费 | 高 | 中 | 剪映/花儿朵朵推出免费 AI 视频功能 | 强化千企千面+本地化壁垒, 而非价格战; 加速代理商体系覆盖 |

| 平台政策变更 (抖音限制 AI 内容) | 中 | 高 | 抖音发布 AI 内容新规, 限制分发 | 加强与抖音的合规沟通, 确保 AI 标识完全符合平台要求 |
| 代理商推进不力 | 中 | 中 | 签约代理商 3 个月无产出 | 收缩代理商数量, 转为直营获客+标杆城市打法 |

### 14.3 合规与安全风险

| 风险 | 发生概率 | 影响 | 触发条件 | 回滚动作 | 恢复条件 |
|------|:---:|:---:|---------|---------|---------|
| 内容违规逃逸 (平台下架) | 中 | 高 | 收到平台下架通知 | 立即冻结该商户发布权限, 全量内容紧急复审, 暂停新内容发布 | 合规团队确认流程修复, 误拦率 < 3% |
