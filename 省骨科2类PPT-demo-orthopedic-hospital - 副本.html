数据同步机制

// 野外/基地环境：数据存本地SQLite，完全离线可用 // 有网络时：自动加密同步至院内服务器 // 专家巡诊前：提前同步运动员历史数据至本地 本地SQLite ──加密同步──→ 院内服务器 院内服务器 ──预同步──→ 本地离线查看
