# 渔伴 Yuban — Figma Demo 设计说明文档

## 一、产品概览

**产品名**：渔伴 Yuban
**Slogan**：钓鱼不孤单
**产品定位**：钓鱼社交小程序 — "钓鱼版小红书+大众点评+滴滴打船"
**目标用户**：25-55岁钓鱼爱好者
**平台**：微信小程序（375×812 视口）

---

## 二、设计系统 Design Tokens

### 2.1 品牌色

| Token | 色值 | 用途 |
|-------|------|------|
| Primary | `#07C160` | 主按钮、选中态、品牌标识 |
| Primary Dark | `#00A650` | 渐变底部、按下态 |
| Primary Light | `#E8F8EE` | 浅绿背景、标签底色 |
| Danger | `#FA5151` | 价格、警告、错误 |
| Warning | `#FFA500` | 星级评分、中等状态 |
| Info | `#1A73E8` | 链接、标签 |
| Text Primary | `#333333` | 正文 |
| Text Secondary | `#666666` | 次要文字 |
| Text Muted | `#999999` | 辅助说明文字 |
| Bg Page | `#F5F5F5` | 页面背景 |
| Bg Card | `#FFFFFF` | 卡片背景 |
| Divider | `#F0F0F0` | 分割线 |

### 2.2 字体

- 系统默认中文字体（PingFang SC / Microsoft YaHei）
- 字号梯度：20rpx(10px) / 22rpx(11px) / 24rpx(12px) / 28rpx(14px) / 30rpx(15px) / 32rpx(16px) / 36rpx(18px) / 44rpx(22px)
- 行高：1.5–1.7

### 2.3 圆角与阴影

- 卡片圆角：16rpx
- 按钮圆角：8rpx
- 标签圆角：6rpx（小）/ 32rpx（胶囊）
- 头像圆角：50%（圆形）
- 卡片阴影：`0 2px 12px rgba(0,0,0,0.06)`
- 品牌卡片阴影：`0 8px 24px rgba(7,193,96,0.25)`
- 悬浮按钮阴影：`0 4px 16px rgba(7,193,96,0.4)`

### 2.4 图标风格

- Emoji风格的功能图标（钓鱼、天气、昆虫等）
- 线性图标用于导航和操作
- TabBar图标：24×24px，灰度#999，选中#07C160

## 四、弹窗/浮层组件

### 4.1 发布动态弹窗（社区页）

- **触发**：点击FAB悬浮按钮
- **动画**：从底部滑入，背景渐显
- **内容**：类型选择 + 文本输入 + 发布按钮
- **关闭**：点击蒙层或✕按钮

### 4.2 发起约钓弹窗（约钓页）

- **触发**：点击FAB悬浮按钮
- **表单字段**：
  - 目标钓点（文本输入）
  - 日期选择（文本输入，后期替换为日期选择器）
  - 最多人数（数字输入）
  - 要求/备注（文本输入）
- **提交按钮**：全宽绿色主按钮

### 4.3 确认对话框（通用）

- **标题**：居中加粗
- **内容**：灰色小字
- **按钮**：取消(灰底) + 确认(绿底)

## 五、用户流程 User Flows

### 5.1 核心流程1：查看钓鱼指数并出发

```
首页 → 钓鱼指数卡片自动加载
     → 查看气象数据 + 蚊虫等级
     → 点击「装备清单」
     → 查看推荐装备
     → 点击「附近钓点」
     → 钓点地图 → 选择钓点
     → 钓点详情 → 查看今日适钓指数
     → 点击「一键导航」
     → 打开微信地图导航
```

### 5.2 核心流程2：发布鱼获动态

```
社区Tab → 点击FAB[+]
        → 底部弹窗弹出
        → 选择类型「鱼获」
        → 输入文字内容
        → (未来)选择图片
        → 点击「发布」
        → Toast提示成功
        → 动态刷新出现在Feed顶部
```

### 5.3 核心流程3：找陪钓并下单

```
约钓Tab → 点击「陪钓服务」Tab
        → 浏览服务者列表
        → 点击某个服务者查看详情
        → 点击「立即预约」
        → 选择时间+时长
        → 确认订单信息
        → (未来)微信支付
        → 订单创建成功
```

### 5.4 核心流程4：约钓匹配

```
约钓Tab → 浏览招募中的约钓
        → 看到感兴趣的活动
        → 点击「加入」
        → 系统发送申请
        → 创建者确认
        → 约钓成功 → 消息通知
```
