四个场景，同一个核心矛盾

数据断层 + 标准缺失 —— 为什么需要做这件事？

🏥 门诊徒手查体

核心痛点：主观定性判断，无客观量化标准

临床后果：评估误差大，不同医生结果不可比。医生靠"肉眼看+手比划"，数据不可追溯。

📋 运动处方开具

核心痛点：纯人工配制，无个性化推荐

临床后果：效率低，处方千人一面。治疗师凭经验逐条配置，无法基于量化评估做个性化调整。

🏃 运动队院外保障

核心痛点：专家无法实时覆盖，院内外数据不通

临床后果：疑难病例延误，伤病预警滞后。驻队医师与院内专家之间缺乏标准化的数据通道。

📱 复诊随访管理

核心痛点：随访率 <10%，数据完全缺失

临床后果：无法评估长期疗效，科研无数据支撑。医生靠私人微信随访，数据不存档、不可追溯。

客户的共同诉求

  • 不需要改造现有HIS和业务流程
  • 不需要额外采购硬件设备
  • 需要可追溯、可对比、可存档的客观数据
  • 需要降低医生负担，而非增加工作量

场景一：徒手查体智能化

从"肉眼看+手比划"到"摄像头量化+自动报告"

❌ 改造前（人工模式）

• 目测角度 + 手写描述
• 输出"活动度大致正常"
• 手工填写报告 2-3分钟
• 纸质报告，难以追溯

✅ 改造后（AI辅助模式）

✓ 语音说出动作名，摄像头自动拍摄
✓ 左肩前屈178°，右肩175°，评分96分
✓ AI自动生成报告 <10秒
✓ 结构化数据，支持复诊对比和科研

部署要求

现有电脑 + 普通摄像头即可，无需红外/深度相机，完全离线运行。

🎤 强调"零硬件新增"、"零流程改造"——医生只需多说一句口令、多看一眼屏幕。这是最容易落地的模块。

场景三：运动队院外保障

专家资源下沉到训练基地，院内外数据实时同步

🖥️ 驻队便携查体

实现：笔记本+摄像头，离线运行

解决：徒手检查有量化标准，和院内统一

📹 远程实时会诊

实现：加密视频通话+AI数据共享

解决：疑难病例一键连线专家，不延误

📊 批量伤病筛查

实现：手机拍视频→批量AI分析→标记异常

解决：1小时处理100+人，专家只核异常

数据同步机制

// 野外/基地环境下：数据存本地SQLite，完全离线可用 // 有网络时：自动加密同步至院内服务器 // 专家巡诊前：提前同步运动员历史数据至本地，离线查看 本地SQLite ──加密同步──→ 院内服务器 院内服务器 ──预同步──→ 本地离线查看

和院内同一套标准、同一套数据格式，驻队查体结果回到院内可以直接对比，解决院外保障"与院内脱节"的老问题。
